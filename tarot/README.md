# タロット占い 🔮 — `tarot/`

タロットカードによる占いのWebアプリ。2ページ構成:

| ファイル | 内容 |
|---|---|
| `index.html` | **タロット占い** — ワンオラクル / スリーカードのスプレッドでカードを引く。逆位置にも対応し、カードの意味を表示 |
| `quiz.html` | **タロットクイズ** 🃏 — カードの意味を当てるクイズ。正解数・スコアを表示 |

ランチャー（アプリひろば）には「タロット占い」と「タロットクイズ」の
2つのアイコンとして登録されている。

## 動かし方

ビルド不要の単一 HTML ファイル×2。ブラウザで開くだけ。
