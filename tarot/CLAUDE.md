# CLAUDE.md — tarot

単一 HTML ファイル×2（`index.html` 占い / `quiz.html` クイズ）。ビルドなし。
共通規約はルートの `CLAUDE.md` を参照。

- カードデータ（意味・正位置/逆位置）は各 HTML にインラインで持つ。
  2ファイルでデータが重複しているので、カードの意味を直すときは両方確認する。
- ランチャーからは2エントリ（`tarot/` と `tarot/quiz.html`）でリンクされている。
  ファイル名を変えるならルート `index.html` も更新する。
- **変更したファイルの `.app-version` のバージョンを必ず上げること**
  （`index.html` はヘッダー内、`quiz.html` はイントロ画面のスタートボタン下）。
  バージョンは2ファイルで独立 — 直した方だけ上げればよい。iPhone のホーム画面
  から開いたときに更新が届いたか確認する唯一の手段。
