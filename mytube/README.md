# MyTube

フォルダの中の動画を YouTube 風の見た目で見るための動画プレイヤーです。ローカルのフォルダ・
OneDrive リンク・YouTube のプレイリストを**同時に**開いて、1つのライブラリとして
まとめて閲覧できます。左サイドバーは「ローカル」「OneDrive」「YouTube」の
3グループに分かれて表示されます。

## 使い方

1. アプリを起動し、右上の「ローカル」から動画が入ったフォルダを選びます。何度でも
   繰り返して、複数のフォルダを同時に開けます(後から選んだフォルダは追加され、前のフォルダは
   消えません)。
2. サブフォルダも自動的に再帰スキャンされ、フォルダ構造がそのまま左サイドバーにツリー表示されます
   (サブフォルダの中のサブフォルダも展開できます)。フォルダをクリックすると、その配下(ネストした
   サブフォルダも含む)の動画に絞り込まれます。**再生中に別のフォルダを選んでも再生は止まりません**
   (下の動画一覧がその絞り込みに従うだけです)。動画を開くとプレイヤーを大きく表示するため
   サイドバーは自動的に隠れます ― 視聴中でもフォルダを切り替えたい場合は、左上の
   サイドバーアイコン(またはプレイヤーを閉じる)でいつでも再表示できます。
3. 動画一覧から動画をクリックすると、YouTubeの視聴ページのように動画プレイヤーが画面いっぱいに
   表示され、下の一覧は隠れます。代わりにプレイヤー右側にYouTubeと同じ「次の動画」リストが
   画面下まで並び、クリックでその動画にすぐ切り替えられます(絞り込み中の一覧の並び順で、
   現在再生中より後ろの動画だけを表示)。一覧に戻るにはプレイヤー右上の✕ボタンを押してください。
   上部の表示形式ボタンで「グリッド」(サムネイル一覧、既定)・「ハイブリッド」(名前・長さ・
   ソース(ローカル/OneDrive/YouTube)・チャンネルの4列を持つ、小さいサムネイル付きのFinderの
   リスト表示のような表形式)を切り替えられます。選んだ形式は次回起動時も保持されます。
4. 動画情報の「自動再生」トグル(既定オン)がオンの間は、最後まで再生すると一覧の並び順で
   次の動画が自動的に再生されます。オフにすると最後まで再生した動画で止まります(設定は
   次回起動時も保持されます)。
5. プレイヤーの動画コントロールバー右下のボタンでフルスクリーン表示に切り替えられます。上部の
   ミニプレーヤーボタン(枠に小さい四角のアイコン、動画再生中のみ有効)を押すと、ウィンドウが
   動画サイズだけの小さいウィンドウになり、画面右下に寄って常に他のアプリより手前(他のSpace・
   フルスクリーンアプリの上にも)に表示されます。動画を見ながら別の作業をしたいときに使って
   ください。ウィンドウの端をドラッグすればサイズも変更できます(16:9を保ったまま伸縮)。
   動画右上の拡大アイコン(矢印)のボタン、またはウィンドウ左上の緑丸ボタンで、ミニプレーヤーに
   入る前のウィンドウサイズ・位置に戻ります(隣の✕ボタンはミニプレーヤーごとプレイヤーを
   閉じます)。
6. チャンネル名の横のメニューから再生速度(0.5x〜2.0x)を選べます。動画を切り替えても速度は保持されます。
7. 上部の検索欄でタイトルを絞り込めます。
8. 次回起動時は、前回開いていたフォルダ・OneDriveリンク・プレイリストに加え、**登録済みの
   OneDriveリンク/プレイリストは閉じていても**すべて自動的に読み込みます(下記
   「開いているライブラリの管理」参照)。
9. 上部の「並び替え」メニューから並び順を選べます: タイトル(A→Z/Z→A)、更新日時が
   新しい順/古い順(既定はタイトルのA→Z順)。

## 開いているライブラリの管理

複数のフォルダ・OneDriveリンク・プレイリストを開くと、左サイドバーに
「ローカル」「OneDrive」「YouTube」の3グループに分かれてそれぞれ並びます。
行にマウスを乗せると✕ボタンが出るので、そこから直接アンロードできます。**閉じるまでは、
次回起動時も自動的に読み込まれ続けます**(明示的に閉じない限りロードされたまま、という
仕様です)。同じフォルダ/同じOneDriveリンク/同じプレイリストをもう一度開くと、追加ではなく
中身の再読み込み(更新)になります。

対応形式: mp4, mov, m4v, avi, mkv, webm, wmv, flv, mpg, mpeg, 3gp

## OneDriveリンクを開く

右上の「OneDrive Link」から、OneDrive の「リンクを知っている全員が閲覧可能」な共有フォルダ/動画の
URL(`https://1drv.ms/...` など)を「名前」を付けて登録すると、サインインなしで中身を一覧・再生できます。
一度登録すれば、次回以降は**起動するだけで自動的に**そのライブラリが開きます(手動で選び直す
必要はありません。登録は複数件可能。シートを開いて名前をクリックすれば、閉じたものを
すぐ開き直すこともできます)。

- **ローカルフォルダ・複数のOneDriveリンクはすべて同時に開けます**。1つ読み込んでも他は消えず、
  ホーム画面には開いている全ソースの動画がまとめて表示されます(サイドバーのツリーでは、
  開いているフォルダ・OneDriveリンクごとに登録した名前をトップに、その配下にサブフォルダが
  そのままネスト表示されるので、ローカルのサブフォルダや他のリンクと混ざりません)。
  同じリンクをもう一度選ぶと追加ではなく中身の再読み込みになります。
- サムネイル・タイトル等は表示されますが、共有元のファイル自体を操作する手段がないため
  **削除できるのはローカルに保存したコピーだけ**です(下記「ローカルへの保存(トグル)」参照)。
- 動画の再生用URLは1時間程度で失効するため、フォルダを開いてから長時間経つと再生に失敗することがあります。
  再生に失敗した場合(URL失効・コーデック非対応・ファイル破損など)は、視聴画面にポップアップで
  エラー内容が表示されます。OneDriveの動画がURL失効で失敗した場合はポップアップの
  「再読み込み」ボタンでその場で再スキャン→再生を再開できます(ローカルに保存済みの動画は
  そもそもURL失効の影響を受けません)。
- **開いたフォルダ・OneDriveリンクは、明示的に閉じるまで次回起動後もずっと自動的に読み込まれます**
  (「開いているライブラリの管理」参照)。OneDriveリンクの読み込みに失敗した場合(リンクが
  無効化された等)は、OneDriveリンクのシートが自動的に開いてエラー内容が表示されます。
- OneDrive が公式に公開しているAPIではなく、Web版クライアントが使っている内部APIを利用しているため、
  Microsoft側の仕様変更で突然使えなくなる可能性があります。

### ローカルへの保存(トグル)

OneDrive の動画は、再生自体は常にストリーミングですぐ始まりますが、ローカル
(`~/Library/Application Support/MyTube/downloads/`)への保存は**トグルで自分から
オンにしたときだけ**行われます(既定はオフ ― 動画を再生しただけでは自動的にダウンロード
されません)。トグルは動画を開いた視聴画面(タイトルの下)にあります。

オンにするとその場でダウンロードが始まり、進捗バー→完了後はファイルサイズがトグルの横に
表示されます。一度保存された動画は、次回以降そのローカルファイルを優先して再生します
(再生用URLの有効期限切れの影響を受けず、ネットワークが無くても再生できます)。

ダウンロード中・保存済みのどちらの状態でもトグルをオフにすると、確認ダイアログが出ます。
「オフにする」を選ぶとダウンロード中なら中断、保存済みならローカルコピーをゴミ箱へ移動します
(いずれもOneDrive上の元ファイルは削除されません)。ホームグリッドのサムネイルを右クリック→
「ローカルコピーを削除」からも同様に削除できます。

動画1本ずつではなくフォルダ単位でまとめて保存したい場合は、左サイドバーのフォルダを
右クリック→「配下をすべてダウンロード」から、そのフォルダとサブフォルダ配下の動画を
まとめて保存できます(OneDrive/YouTubeのフォルダのみ。既にダウンロード中/保存済みの
動画はスキップされます)。

右上の「キャッシュ」ボタンからは、現在のローカルキャッシュの合計サイズ・件数を確認できるほか、
**上限(GB、既定5GB)**を設定できます。合計サイズが上限を超えると、更新日時の古いものから
自動的にゴミ箱へ移動されます(直近再生した動画から真っ先に消えることはありません)。
**一気にまとめて削除**したい場合は、同じポップオーバーの「すべて削除」から。OneDrive・
YouTube両方のダウンロード済みコピーをまとめてゴミ箱へ移動します(件数と合計サイズを
確認してから削除します)。ダウンロードのやり直しがきくキャッシュなので、ディスク容量を
空けたいときにまとめて掃除する用途を想定しています(これもOneDrive/YouTube上の元動画には
影響しません)。

なお、**ローカルフォルダの動画本体は、アプリ内から直接削除できません**(誤操作のリスクを
避けるため)。右クリックの「Finderで表示」でFinderを開き、そこで削除等を行ってください。

## YouTube プレイリストを開く

右上の「Youtube Playlist」から、YouTube のプレイリストURL
(`https://www.youtube.com/playlist?list=...`)または単体動画のURLを貼り付けて登録すると、
一覧をサムネイル・タイトル付きで読み込みます(登録・自動復元・複数同時オープン・アンロードの
操作感はOneDriveリンクと同じです)。**名前は入力不要**で、プレイリストのタイトルを
yt-dlpから自動取得して使います(OneDriveと違い名前欄はありません)。

- OneDriveと違い、YouTube の動画は**再生を選ぶと `yt-dlp` によるダウンロードが始まり、
  ダウンロードが完了してから再生が始まります**(映像と音声が別ストリームで配信されている
  ことが多く、単純な直接ストリーミングができないため)。再生画面には取得の進捗が表示されます。
- ダウンロードした動画は`~/Library/Application Support/MyTube/downloads/`にmp4として保存され、
  次回以降はそのローカルファイルを再生します(OneDriveの「ローカルへの保存(トグル)」と同じ場所・
  同じ削除操作 ― ホームグリッドの右クリックまたは視聴画面のゴミ箱アイコンでローカルコピーだけを
  削除でき、YouTube上の動画自体には影響しません)。
- 画質は1080p以下でH.264(`avc1`)コーデックの映像を明示的に選びます(1080pのH.264が
  無い動画は取得可能な最高画質に自動的に下がります)。コーデックを指定しないと、YouTubeが
  「best」として返す映像がVP9/AV1(macOSのAVFoundationがデコードできない)になることがあり、
  「音は出るが映像が出ない」不具合の原因になっていたための対策です。
- **`yt-dlp`と`ffmpeg`が必要です**(Homebrew前提、同梱していません: `brew install yt-dlp
  ffmpeg`)。見つからない場合はダウンロードが失敗し、視聴画面にエラーメッセージが表示されます。

## サムネイルについて

各動画の数秒地点のフレームを自動生成し、`~/Library/Caches/MyTube/thumbnails/` にキャッシュします。
元の動画ファイルが更新されると、次回表示時に自動で再生成されます。

## ビルド

```bash
swift build         # コンパイル確認
./build_app.sh       # MyTube.app を生成
./install.sh         # ビルド → /Applications へインストール
```

## 権限について

デスクトップ/書類/ダウンロードフォルダなど macOS がプライバシー保護対象にしているフォルダを
指定する場合、初回はアクセス許可のダイアログが出ることがあります。継続的にアクセスできない場合は
「システム設定 → プライバシーとセキュリティ → フルディスクアクセス」に MyTube を追加してください。
