# CLAUDE.md — sansu

単一 HTML ファイルの算数学習アプリ（たしざん + 九九）。ビルドなし・依存なし。
共通規約はルートの `CLAUDE.md` を参照（Nunito フォント・ダークグラデ・
モバイルファースト・絵文字アイコン）。

- 旧 `tashizan/`（学習RPG）と `kakeizan/`（九九）の統合版。**ゲーム要素
  （バトル・ショップ・コイン・HP/EXP・実績・効果音・セーブ）は意図的に
  排除してある**。再追加するときはユーザーに確認すること。
- 九九の読み上げは `speechSynthesis`。進行状況は保存していない
  （`localStorage` 不使用）。
- UI はひらがな中心の子ども向け日本語。漢字を増やさない。
- 変更後は `index.html` をブラウザで直接開いて動作確認する。
