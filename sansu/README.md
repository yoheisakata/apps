# さんすうれんしゅう 🧮 — `sansu/`

子ども向けの算数練習アプリ（Webアプリ）。旧「たしざんクエスト」（`tashizan/`）と
「くくをおぼえよう」（`kakeizan/`）を統合し、ゲーム要素（バトル・ショップ・コイン・
レベルアップ・実績など）を排除した学習専用版。

## 機能

- **たしざん** — 難易度別（レベル1〜5）の足し算問題。1セット10問の4択形式で、
  絵文字による数の視覚化つき。終了時に正解数を表示。
- **かけざん（くく）** — 段（だん）を選んで九九を順に覚える学習カード。
  Web Speech API（`speechSynthesis`）による読み上げつき。
  「🔊 もういちど」で発音を聞き直せる。
- ひらがな中心の子ども向け UI

進行状況の保存は無い（`localStorage` 不使用。開くたびに最初から）。

## 動かし方

ビルド不要の単一 HTML ファイル。`index.html` をブラウザで開くだけ。
GitHub Pages のランチャー（アプリひろば）には「さんすう れんしゅう」として
掲載されている。
