# MyGallery Pad

iPad用のミニ写真・動画ギャラリー。**OneDriveの共有リンクだけ**を対象にした、
mygallery(Mac版)の縮小版として作られました。ローカルフォルダのブラウズ・
Visionベースの画質順ソート・重複検出・回転・削除には対応していません
(いずれもiPadの制約上そのままの形では成立しないため ― `CLAUDE.md`参照)。

## 使い方

1. アプリを起動すると、ホーム画面が開く。OneDriveリンクは2件(動画専用「ビデオ」・
   写真専用「写真」、追加・削除はできない ― 下記「リンクについて」参照)。それぞれ
   起動直後に年フォルダの一覧を自動で取得し(この時点ではまだ写真・動画そのものは
   取得しない)、年ごとのチップが表示される。
2. 年チップをタップするとその年の全月を一括で選択/解除できる。年チップの右の
   ▽ボタンを押すと、その年の月フォルダのチップが下に展開され、月単位でも
   選択/解除できる(月だけ外す・年ごと外す、どちらも可能)。各リンクに「全選択」/
   「全非選択」ボタンもある。
3. スライドショーの写真表示秒数・シャッフルもこの画面で設定できる。
4. 「グリッドを開く」を押すと、選んだ年/月フォルダに該当する写真・動画をその
   タイミングで初めてOneDriveへ取得しに行き(少し待つことがある)、サムネイル
   グリッド画面が開く。
5. サムネイルをタップすると全画面ビューアが開く。左右スワイプ(または画面下の
   ボタン)で前後の写真・動画へ移動できる。動画は標準の再生バーで再生・シーク
   できる。画面をタップするとコントロールの表示/非表示を切り替えられる。
6. グリッド画面右上の再生ボタン、またはビューア内の再生ボタンから、今表示中の
   アイテム全体を対象にフルスクリーンのスライドショーを開始できる。
   - 写真は一定秒数(既定6秒)表示したら次へ進む。
   - 動画は最後まで再生してから次へ進む。
   - 画面をタップすると下部に一時停止/前後送り/終了ボタンが3秒だけ現れる。
   - Magic Keyboard等の外部キーボードを接続していれば、スペース(一時停止/再開)、
     ←→(前後の写真・動画へ)、esc(終了)でも操作できる。
7. グリッド画面右上の「戻る」でホーム画面(フォルダ選択)に戻れる。「再読み込み」
   ボタンを押すと、選択中のフォルダをもう一度OneDriveへ取得しに行く(署名付き
   ダウンロードURLが1時間程度で失効するため、しばらく開きっぱなしにしたときの
   再取得に使う)。

選んだ年/月フォルダはリンクごとに端末へ保存され、次回起動時も同じ選択で開く。

## リンクについて

OneDriveリンクはアプリのコードに直書きされた固定の2件だけで、アプリ内から
追加・削除する画面は無い(リンクはめったに変わらないため ― mygallery(Mac版)/
myslideshow-ipadと同じ方針)。リンク自体や年の範囲を変える場合は
`Sources/MyGalleryPad/ContentView.swift`の`links`配列を直接編集する。

## インストール(無料Apple IDでの7日間運用)

Apple Developer Programに入っていない場合、無料のApple IDでもXcodeから実機に
インストールできますが、**7日ごとに再インストールが必要**です。

1. `mygallery-ipad`フォルダをMacで開き、ターミナルで以下を実行してXcode
   プロジェクトを生成します(初回、および`project.yml`を変更した後は毎回必要):
   ```bash
   xcodegen generate
   open MyGalleryPad.xcodeproj
   ```
2. XcodeでSigning & Capabilities → Teamに自分のApple ID(Personal Team)を選択します。
3. iPadをUSBでMacに接続し、実行先(destination)にそのiPadを選んで▶を押すと
   インストールされます。
4. 7日経つと起動できなくなるので、同じ手順で再インストールしてください。

## 制限事項

- OneDriveの「リンクを知っている全員が閲覧可能」な共有リンクのみ対応。
- OneDriveの非公式内部API(`api-badgerp.svc.ms`)を使っています。Microsoftが
  予告なく仕様変更・遮断する可能性があります。
- 動画のダウンロードURL(`@content.downloadUrl`)は1時間程度で失効します。
  しばらく開きっぱなしで再生できなくなったら、グリッド画面の「再読み込み」で
  再取得してください。
- フォルダの選択はYear(年)/Month(月)の2階層まで(実際のライブラリがさらに
  Day(日)フォルダを持っていても、選択の粒度は月までで十分という判断)。
- ローカルフォルダの読み込みには対応していない(OneDrive共有リンク専用)。
