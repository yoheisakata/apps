# MyGallery Pad

iPad用のミニ写真・動画ギャラリー。**OneDriveの共有リンクだけ**を対象にした、
mygallery(Mac版)の縮小版として作られました。ローカルフォルダのブラウズ・
Visionベースの画質順ソート・重複検出・回転・削除には対応していません
(いずれもiPadの制約上そのままの形では成立しないため ― `CLAUDE.md`参照)。

## 使い方

1. アプリを起動すると、左にOneDriveリンクのサイドバー(動画専用「ビデオ」・
   写真専用「写真」の2件、追加・削除はできない ― 下記「リンクについて」参照)、
   右に選択中リンクのグリッド画面が並ぶ画面になる。
2. サイドバーでリンクをタップすると、そのリンクの年フォルダの一覧を自動で取得し、
   初回は直近の年の写真・動画をその場でOneDriveへ取得しに行って(少し待つことが
   ある)サムネイルグリッドに表示する ― 「開く」ボタンは無く、リンクを選んだだけで
   写真・動画が見え始める。2回目以降にそのリンクを選び直したときは、前回取得した
   一覧がそのまま(再取得せずに)表示される。
3. **サイドバーの各リンク名の左に▽(ディスクロージャ)があり、開くとその年
   一覧がチェックボックス付きの行で並ぶ(2026-09-07追加)。タップで年単位の
   絞り込みを即座に切り替えられる ― フォルダピッカーのシートを開かずに
   年だけならサイドバーからすぐ変更できる。**
4. グリッド画面右上の「年/月を選ぶ」ボタンでフォルダピッカーのシートが開く。
   年チップをタップするとその年の全月を一括で選択/解除でき、年チップの右の
   ▽ボタンを押すとその年の月フォルダのチップが下に展開され、月単位でも
   選択/解除できる(月だけ外す・年ごと外す、どちらも可能)。「全選択」/
   「全非選択」ボタン、スライドショーの写真表示秒数・シャッフル設定もこの
   シートにある。シートを「閉じる」で閉じると、選び直した年/月に該当する
   写真・動画をその時点でOneDriveへ取得しに行き、グリッドが更新される
   (チップを1つ切り替えるたびに取得しに行くわけではない)。サイドバーの年
   フィルターとこのシートはどちらも同じ選択状態を操作するので、片方で変えた
   選択はもう片方にもすぐ反映される。
5. グリッド画面右上の並び替えボタン(⇅アイコンのメニュー)で、新しい順・古い順・
   名前順・サイズが大きい順・サイズが小さい順を切り替えられる(既定は新しい順)。
   新しい順/古い順で並べているときだけ、グリッドに年月ごとの見出し(区切り線)が
   自動で入る。カレンダーアイコン(月日バッジ)・秤アイコン(サイズバッジ)の
   トグルボタンで、各サムネイルの左上/右下にそれぞれの情報を小さく表示できる
   (サイズが大きい/小さい順で並べているときは、このトグルの状態に関わらず
   サイズバッジが常に表示される)。並び替え順・バッジ表示のON/OFFは端末に保存され、
   次回起動時も引き継がれる。
6. サムネイルをタップすると全画面ビューアが開く。左右スワイプ(または画面下の
   ボタン)で前後の写真・動画へ移動できる。動画は標準の再生バーで再生・シーク
   できる。画面をタップするとコントロールの表示/非表示を切り替えられる。
7. グリッド画面右上の再生ボタン、またはビューア内の再生ボタンから、今表示中の
   アイテム全体を対象にフルスクリーンのスライドショーを開始できる。
   - 写真は一定秒数(既定6秒)表示したら次へ進む。
   - 動画は最後まで再生してから次へ進む。
   - 画面をタップすると下部に一時停止/前後送り/終了ボタンが3秒だけ現れる。
   - Magic Keyboard等の外部キーボードを接続していれば、スペース(一時停止/再開)、
     ←→(前後の写真・動画へ)、esc(終了)でも操作できる。
8. グリッド画面を下に引っぱると(プルダウン)、選択中のフォルダをもう一度
   OneDriveへ取得しに行く(署名付きダウンロードURLが1時間程度で失効するため、
   しばらく開きっぱなしにしたときの再取得に使う)。**取得結果が一時的に0件でも、
   すでにグリッドに表示中の写真・動画が消えることはない**(何も表示されていなかった
   ときだけ、空/エラーメッセージが出る)。

選んだ年/月フォルダはリンクごとに端末へ保存され、次回起動時も同じ選択で開く
(初回起動時だけは、選択が無いため直近の年が既定で選ばれる)。

## リンクについて

OneDriveリンクはアプリのコードに直書きされた固定の2件だけで、アプリ内から
追加・削除する画面は無い(リンクはめったに変わらないため ― mygallery(Mac版)/
myslideshow-ipadと同じ方針)。リンク自体や年の範囲を変える場合は
`Sources/MyGalleryPad/ContentView.swift`の`links`配列を直接編集する。

## インストール(無料Apple IDでの7日間運用)

Apple Developer Programに入っていない場合、無料のApple IDでもXcodeから実機に
インストールできますが、**7日ごとに再インストールが必要**です。

1. `mygallery-ipad`フォルダをMacで開き、ターミナルで以下を実行してXcode
   プロジェクトを生成します(初回、および`project.yml`を変更した後は毎回必要):
   ```bash
   xcodegen generate
   open MyGalleryPad.xcodeproj
   ```
2. XcodeでSigning & Capabilities → Teamに自分のApple ID(Personal Team)を選択します。
3. iPadをUSBでMacに接続し、実行先(destination)にそのiPadを選んで▶を押すと
   インストールされます。
4. 7日経つと起動できなくなるので、同じ手順で再インストールしてください。

## 制限事項

- OneDriveの「リンクを知っている全員が閲覧可能」な共有リンクのみ対応。
- OneDriveの非公式内部API(`api-badgerp.svc.ms`)を使っています。Microsoftが
  予告なく仕様変更・遮断する可能性があります。
- 動画のダウンロードURL(`@content.downloadUrl`)は1時間程度で失効します。
  しばらく開きっぱなしで再生できなくなったら、グリッド画面の「再読み込み」で
  再取得してください。
- フォルダの選択はYear(年)/Month(月)の2階層まで(実際のライブラリがさらに
  Day(日)フォルダを持っていても、選択の粒度は月までで十分という判断)。
- ローカルフォルダの読み込みには対応していない(OneDrive共有リンク専用)。
