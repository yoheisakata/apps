# MyMusic

YouTube や Suno / MusicCreator.ai / MusicGPT などの曲リンク、OneDrive の共有フォルダを
プレイリストとして貼り付け、
まとめて再生できる macOS 用のミニ・ミュージックプレーヤーです。Dock にアイコンが出る通常のアプリで、
ウィンドウを閉じても再生は止まりません。

## 使い方

1. `./install.sh` でビルドして `/Applications/MyApplications/` にインストール
2. Launchpad / Dock から起動します
   - ウィンドウを閉じてもアプリは終了せず、再生も続きます。ウィンドウを開き直すには
     Dock のアイコンをクリック(またはメニューの「ウィンドウを開く」)
   - 完全に終了するにはメニューの「MyMusic を終了」(⌘Q)
3. 上部の入力欄に曲のリンク(または OneDrive の共有リンク)を貼り付けて ➕ で追加
   - OneDrive の共有リンクはフォルダごと取り込める。サブフォルダも再帰的にたどって、
     見つかった音声ファイルがまとめて取り込まれ、フォルダ構成のままサイドバーに並ぶ。
     曲数が多いと数十秒かかるため、スキャン中は見つかった曲数がバナーに出る
   - 同じ共有リンクをもう一度貼り付けると、追加済みの曲はスキップされ、共有フォルダに
     増えた曲だけが取り込まれる(同期のように使える)
   - 複数リンクをまとめて追加したいときは、入力欄の隣の 📝 ボタンから「リンクをインポート」を開き、
     1行につき1リンクの形式でテキストを貼り付けて「インポート」を押す
   - インポートで失敗したリンクはスキップされ、シート内にエラー内容が一覧表示される。
     詳細は `~/Library/Application Support/MyMusic/import-errors.log` にも追記される
     (シート内の「エラーログを Finder で表示」からも開ける)
4. 左のサイドバーで聴きたい場所を選び、右の一覧の行をクリックすると再生開始。
   上部のバーでシャッフル/前へ/再生/次へ・シークバー・音量が使えます
   - サイドバーは「すべての曲」「リンク」(YouTube 等で1曲ずつ追加したもの)、
     および OneDrive の共有リンクごとのフォルダツリー。フォルダを選ぶと**その配下の曲すべて**が
     一覧に出て、そのままシャッフル/自動送りの対象(再生キュー)になります
   - 共有リンクの行を右クリックすると「再スキャン(新しい曲を取り込む)」と
     「この共有リンクの曲を削除」が選べます(OneDrive 上のファイルは消えません)
   - 入力欄の右の検索ボックスで曲名・フォルダ名の絞り込みができます
   - シャッフルをオンにすると、次へ/自動送りはプレイリストからランダムに選び、前へは
     実際に再生した順序を遡ります(設定は次回起動時も保持されます)
5. 行は右クリック(またはスワイプ)で一覧から削除できます。ドラッグでの並び替えは
   「すべての曲」を選んでいて検索していないときのみ
   - **削除は MyMusic の一覧から外すだけで、OneDrive 上のファイルは消えません**
     (OneDrive の曲は「外す」と表示されます)。外した曲は共有リンクを再スキャンすれば戻ります

## 対応リンク

| サイト | 方式 |
|---|---|
| YouTube (`youtube.com` / `youtu.be`) | `yt-dlp` + `ffmpeg` で音声を mp3 抽出し、ローカルにキャッシュしてから再生 |
| Suno (`suno.com`) | ページ内に埋め込まれた `audio_url` を直接ストリーミング再生 |
| MusicCreator.ai | ページの `og:audio` メタタグの mp3 URL を直接ストリーミング再生 |
| MusicGPT | ページ内に埋め込まれた `file_output_0` の mp3 URL を直接ストリーミング再生 |
| OneDrive 共有リンク (`1drv.ms` / `onedrive.live.com`) | 「リンクを知っている全員が閲覧可能」な共有フォルダ/ファイルを再帰スキャンし、含まれる音声ファイルを直接ストリーミング再生(サインイン不要) |
| `.mp3` / `.m4a` / `.wav` などへの直リンク | そのままストリーミング再生 |
| その他のサイト | `og:audio` メタタグがあれば再生を試みる(なければ追加失敗) |

YouTube 以外は各サイトが公開しているページ内の音声 URL を読み取っているだけで、
サイト側の実装が変わると取得できなくなる可能性があります。OneDrive も同様に、OneDrive の
Web クライアント自身が使っている API を利用しているため、Microsoft 側の変更で使えなくなる
可能性があります。

OneDrive の曲はダウンロードせずストリーミング再生します(再生用 URL は1時間ほどで失効するため、
再生するたびに自動で取り直します)。再生にはネットワーク接続が必要です。

曲にジャケット画像(アートワーク)が埋め込まれていれば、一覧と再生バーに表示します。
画像は OneDrive 側が曲ファイルから起こしたものを取得し、`~/Library/Caches/MyMusic/artwork/`
にキャッシュします(2回目以降は通信しません)。アートワークが入っていない曲は
♪ のプレースホルダーになります。

## 必要なツール(YouTube リンクのみ)

Homebrew で以下をインストールしてください。

```bash
brew install yt-dlp ffmpeg
```

未インストールの場合、YouTube 以外のリンクは通常どおり使えます。

## データの保存場所

- プレイリスト: `~/Library/Application Support/MyMusic/playlist.json`
- YouTube から抽出した mp3 のキャッシュ: `~/Library/Application Support/MyMusic/cache/`
- インポート失敗ログ: `~/Library/Application Support/MyMusic/import-errors.log`(インポート実行のたびに追記)
- ジャケット画像のキャッシュ: `~/Library/Caches/MyMusic/artwork/`(消しても再取得されます)
