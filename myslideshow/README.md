# MySlideshow

OneDriveの共有リンク(フォルダ)に入っている写真・動画を、テレビのように流しっぱなしで
自動再生するスライドショーアプリ。子どもの写真・動画をまとめてぼーっと見せたいときに使う。

## 使い方

1. アプリを起動すると、ホーム画面が開く。OneDriveリンクは2件(動画専用「動画」・
   写真専用「写真」、追加・削除はできない ― 下記「リンクについて」参照)。それぞれの
   年別チェックリスト(「動画」は2020〜2021年、「写真」は2020〜2026年、決め打ち ―
   下記「リンクについて」参照)が起動直後から即座に出る(この時点ではOneDriveへは
   まだアクセスしない)。
2. 対象にしたい年だけチェックして(片方だけ絞り込み、もう片方は全部、といった使い方も
   できる)、選んだ年はリンクごとに次回も同じ選択で開く。チェックボックスは横に並んで
   折り返す形なので、年の数が多くても縦に間延びしない。各グループに「全選択」/
   「全非選択」ボタンもある。
3. 写真の表示秒数・シャッフル・時間制限(下記)・表示モード(下記)もこの画面で設定し、
   画面最下部中央の「スライドショー開始」を押すと、選んだ年に該当する動画・写真を
   そのタイミングで初めてOneDriveへ取得しに行く(少し待つことがある)。取得できた分を
   合わせて選んだモードで自動再生し始める。
   - 写真は一定秒数(既定6秒)表示したら次へ進む。
   - 動画は最後まで再生してから次へ進む。
   - 操作は不要 ― マウスを動かすと下部に一時停止/前後送り/終了ボタンが3秒だけ現れる。
   - キーボードでも操作できる: スペースキー(一時停止/再開)、←→(前後の写真・動画へ)、
     esc(スライドショーを終了してホーム画面へ戻る)。

## 表示モード

「スライドショー設定」内のセグメントボタンで選ぶ(次回起動時も同じ選択を覚えている)。

- **ウィンドウ内** ― アプリのメインウィンドウをリサイズ可能な大きめサイズ(960×640)に
  広げて、その中で再生する。ホーム画面へ戻るとウィンドウは元の固定サイズ(420×560、
  リサイズ不可)に戻る。
- **全画面**(既定) ― macOSネイティブのフルスクリーンに切り替えて再生する。従来からの
  唯一の挙動。
- **PIP** ― 自前の小さな常時最前面(他のアプリの上にも表示される)浮動ウィンドウで再生する。
  メインウィンドウはホーム画面を表示したまま裏に残るので、他の作業をしながら隅っこで
  流し続けられる。ドラッグで好きな位置へ動かせる。**macOSネイティブの動画専用
  Picture-in-Picture(AVKit)ではない** ― このアプリは写真も扱うため、動画にしか使えない
  AVKitのPIPは採用しなかった。

## リンクについて

OneDriveリンクはアプリのコードに直書きされた固定の2件だけで、アプリ内から追加・削除する
画面は無い(リンクはめったに変わらないため)。それぞれ対象メディアを絞ってある:

- **動画** ― 動画だけを対象にする(写真が混ざっていても表示しない)。年別チェックボックスは
  2020〜2025年。
- **写真** ― 写真だけを対象にする。年別チェックボックスは2020〜2026年。

**年別チェックボックスの選択肢もコードに決め打ちで、OneDriveをスキャンして動的に
取得することはしない**(実際にOneDriveへ取得しに行くのは「スライドショー開始」を
押した瞬間だけ)。リンク自体や年の範囲を変える・増やす場合は`ContentView.swift`の
`links`配列(`availableFolders`が年の選択肢)を直接編集する。

## 日付表示

ファイル名から撮影日を推測できたときは、画面右下に「2023年5月15日」のように小さく表示する
(`IMG_20230515_120033.jpg`のような、カメラ・スマホの標準的な命名規則が対象)。マウスを
動かさなくても常に出ている(前後送り等のオーバーレイと違い、3秒で消えたりしない)。
ファイル名から日付が読み取れないものは何も表示しない。

## 時間制限

スライダーで、スライドショーの最大再生時間を5分刻みで5分〜60分の間に設定できる。
スライダーを右端まで動かすと「無制限」(既定)になる。制限時間に達すると、再生中の
写真・動画を最後まで待たずに自動的にスライドショーを終了してホーム画面へ戻る。

## 制限事項

- OneDriveの「リンクを知っている全員が閲覧可能」な共有リンクのみ対応。サインインが必要な
  リンクや、Google Photos等の他サービスは非対応。
- ローカルフォルダの読み込みには対応していない(OneDrive共有リンク専用)。
- スキャンはフォルダの深さ制限なく全階層をたどる(mytubeと同じ方式)が、**選んだ年
  フォルダだけを辿る**(チェックを外した年やその他のフォルダには一切アクセスしない)。
  さらに兄弟フォルダ(同じ年の中の月フォルダ、同じ月の中の日フォルダ等)は最大8並列で
  同時に取得する(2026-08-30、絞り込みだけでは年フォルダ自体が年/月/日と深くネストして
  いると逐次アクセスの回数が変わらず遅いままだったため)。それでも階層が非常に深い・
  フォルダ数が非常に多いライブラリで多くの年を選んでいる場合は、「スライドショー開始」を
  押してから実際に始まるまで時間がかかることがある。
- OneDriveの署名付きダウンロードURLは1時間程度で失効するが、スキャンは「スライドショー
  開始」を押すたびに毎回行うため、通常は気にしなくてよい(長時間流しっぱなしにしていて
  途中で再生できなくなった場合は、一度ホーム画面に戻って開始し直す)。
- 写真・動画を選ぶ順序は「フォルダ名→ファイル名」のアルファベット順(シャッフル有効時は
  ランダム)。撮影日時順の並び替えは今のところ無い。

## ビルド / インストール

```bash
./build_app.sh   # MySlideshow.app をビルド
./install.sh     # ビルドして /Applications/MyApplications に登録
```
