# Renamer

Better Rename 9（Intel 専用のため Rosetta 廃止後は動かなくなる）の代替として作った、
Apple Silicon ネイティブの一括リネームアプリ。SwiftUI 製・依存なしの単一ソースファイル。

macOS 13+ / arm64 ネイティブ

## 機能

[A Better Finder Rename](https://www.publicspace.net/BetterRename/) の主要機能を再現している。

- ファイル / フォルダをドラッグ＆ドロップ（または「ファイルを追加」）でリストに追加
- ルールを複数組み合わせて上から順に適用:
  - **検索と置換** — 正規表現・大文字小文字の同一視に対応
  - **テキストを追加** — 先頭 / 末尾 / 位置指定
  - **連番を追加** — 開始番号・増分・桁数・区切り文字・位置
  - **日付を追加** — 変更日 / 作成日 / **EXIF撮影日** / 現在日時、書式は DateFormatter 形式
  - **メタデータを挿入** — 音楽タグ（曲名・アーティスト・アルバム・トラック番号、MP3/M4A/FLAC 等）と画像サイズ（幅x高さ）
  - **大文字・小文字** — すべて小文字 / すべて大文字 / 単語の先頭を大文字
  - **文字を削除** — 先頭 / 末尾から N 文字
  - **名前を切り詰め** — 先頭 / 末尾の N 文字だけを残す
  - **クリーンアップ** — 前後の空白削除、連続空白の圧縮、アンダースコア⇔空白変換
  - **Windows互換名に変換** — NTFS/SMB で使えない文字 `< > : " / \ | ? *` を置換、末尾のドット・空白を削除
  - **拡張子を変更** — 空にすると拡張子を削除
- **ルールごとの拡張子フィルタ** — 例: `jpg, png` と指定するとそのルールは画像だけに適用（連番もフィルタ内だけで数える）
- **プリセット** — ルール一式に名前を付けて保存・呼び出し・削除、JSON での書き出し / 読み込み
- リネーム前のライブプレビュー（変更後の名前を右側に表示）
- 名前の衝突（重複・既存ファイルとの競合）を赤色で警告し、実行をブロック
- **複数回の「元に戻す」**（バッチ単位で何回でも遡れる）
- **リネーム履歴ログ** — 全リネームを `~/Library/Application Support/Renamer/history.log` に記録（左下の時計アイコンから開ける）
- リストの並べ替え（名前 / 変更日）とドラッグでの手動並べ替え（連番の順序に反映）
- フォルダ自体のリネームにも対応（中のファイルも同時にリネーム可）

## EXIF / メタデータ対応形式

- 画像（ImageIO）: JPEG, HEIC/HEIF, PNG, TIFF, および主要 RAW（ARW, CR2/CR3, NEF, RAF, ORF, DNG, PEF ほか）
- 音楽・動画（AVFoundation）: MP3, M4A, AAC, FLAC, WAV, AIFF, MP4, MOV

## インストール

```bash
./install.sh
```

ビルド（アイコン生成込み）→ `/Applications/Renamer.app` への登録まで自動で行う。
以後は Launchpad や Spotlight から「Renamer」で起動できる。

ビルドだけなら `./build.sh`。アイコンだけ作り直すなら `swift make-icon.swift`。
ad-hoc 署名のローカルビルドなので、自分の Mac でビルドすれば Gatekeeper の警告なしに起動できる。

## ファイル構成

- `Sources/main.swift` — アプリ本体（SwiftUI、単一ファイル）
- `make-icon.swift` — アイコン生成（紫グラデ + RN。youtube-dl-mac と同デザイン）
- `build.sh` / `install.sh` — ビルド / インストールスクリプト
- `Info.plist` — バンドル設定

## 制限事項

- ルールは拡張子を除いたファイル名部分に適用される（拡張子は「拡張子を変更」ルールでのみ変更）
- バッチ内でのファイル名の入れ替え（A→B と B→A を同時に行う）は衝突として扱われ実行できない
- タグの読み取りは対応形式でメタデータが存在する場合のみ（取得できないファイルはそのルールをスキップ）
