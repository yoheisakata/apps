# ⚫ 五目並べ

ブラウザだけで遊べる五目並べ(Gomoku)アプリ。ビルド不要・依存ライブラリなしの単一 HTML ファイル。

## 遊び方

- ホーム画面で「対AI対戦」か「2人対戦」を選ぶ
- 対AI対戦では、黒(先手)/白(後手)と強さ(やさしい/ふつう/つよい)を選べる
- 盤の交点(線が交わる点)をタップして石を置く。碁盤と同じく、マスの中ではなく交点に石が乗る
- 黒が先手・白が後手で交互に打つ。5個(以上)連続で並べたプレイヤーの勝ち
- 盤面が全て埋まって勝者が出なければ引き分け
- 決着がつくと結果が表示される

## ルール実装メモ

- 縦・横・斜め(2方向)のいずれかで自分の色の石が5個以上連続すれば勝ち
- **オーバーライン(6個以上の連続)も勝ちとして扱う**(フリースタイル・ルール採用。禁じ手なしのシンプルな五目並べ)
- 黒の三三・四四などの禁じ手(連珠ルール)は実装していない — 先手・後手どちらでも自由に打てる
- 盤面は伝統的な15×15

## 技術メモ

- `index.html` 単体で完結(インライン CSS/JS)、ビルドステップなし
- 盤は将棋と違い「交点に石を置く」碁盤スタイル。各交点セルに CSS の疑似要素で縦横の線分を描画し、端の交点だけ線を半分にして盤の外に線がはみ出さないようにしている
- 勝敗判定 `checkWin(board, r, c, player)` は、石を置いた直後にその石を中心として4方向(横・縦・右下がり斜め・右上がり斜め)へ前後にどこまで同色が連続するかを数える方式。境界チェック (`inBounds`) を丁寧に行っており、盤端で連が途切れる/誤検出するケースがないことをテスト済み(下記)
- AI は「候補手をスコアリングして選ぶ」ヒューリスティック + 浅いネガマックス(αβ枝刈り)のハイブリッド:
  1. 自分が即座に5並びを作れる手があれば最優先で打つ
  2. 相手が次に5並びを作れる手があればブロックする(難易度が低いほどこのブロックを見逃す確率を上げてある)
  3. それ以外は、連の長さと両端の空き具合(「開いた三」「片側だけ空いた四」など)を得点化する評価関数で候補手をスコアリングし、「つよい」では2手先まで軽量なネガマックス探索で読む
  - 探索候補は盤全体(15×15=225マス)ではなく、既存の石から半径2マス以内の空きマスのみに絞ることで、深く読んでも1手あたり十分高速(体感で1秒未満)
