# CLAUDE.md — pgquiz

単一 HTML ファイルの PostgreSQL 学習アプリ（クイズ + フラッシュカード）。
ビルドなし・依存なし。共通規約はルートの `CLAUDE.md` を参照（Nunito フォント・
ダークグラデ・モバイルファースト・絵文字アイコン）。

- 出題データは `QUESTIONS` 配列（`index.html` 内の `<script>`）にハードコード。
  各問題は `{ cat, q, choices, answer(正解のindex), note(解説), fig(任意) }`。
  クイズ・フラッシュカード両モードが同じデータを共有している。
- `fig` は `FIGURES` マップのキーを指す任意項目。図はインラインSVG文字列として
  `FIGURES` に定義し、**回答後の解説欄とフラッシュカードの裏面にだけ**表示する
  （問題文と一緒に出すと答えのネタバレになる図があるため、問題側には出さない）。
  色はダークテーマ直書き（#6cace4 / #2ed573 / #ff4757 / #e9f1fa / #8fa7bd）。
- **対象は PostgreSQL 17 以降**。バージョン固有の内容を足す/直すときは、その
  バージョンで実際にリリースされた機能かどうかを確認してから記載すること
  （未確認のまま新バージョンの推測機能を書かない）。
- カテゴリの追加/削除は `QUESTIONS` に項目を足すだけでなく、`CATEGORY_EMOJI`
  にも対応する絵文字を追加すること（カテゴリ選択画面の生成に使われる）。
- クイズのヒントは per-question のヒント文ではなく、誤答2択を消す方式
  （`useQuizHint()`）。1問1回、使用回数は結果画面に出す。問題データに
  ヒント用のフィールドは存在しない。
- 進行状況は保存していない（`localStorage` 不使用）。
- 画面切り替えは `document.body` への1つの click delegation（`data-action`
  属性）で行う。
- 変更後は `index.html` をブラウザで直接開いて動作確認する。特に選択肢の
  グリッドとフラッシュカードのフリップは、狭い画面幅でも確認すること。
