# AWS SAP 対策 ☁️ — `awsquiz/`

AWS Certified Solutions Architect – Professional (**SAP-C02**) 向けの学習アプリ（Webアプリ）。
iPhone で片手で回せることを前提にした、クイズ中心の試験対策ツール。

## 機能

### 学習モード

- **⚡ 今日の練習** — 苦手・未着手の問題を優先して10問。カテゴリを選ぶ手間なく始められる。
- **📝 分野別クイズ** — 出題範囲を選んで10問。範囲は二軸で選べる。
  - **試験ドメイン**: 組織の複雑さ(26%) / 新規設計(29%) / 継続的改善(25%) / 移行と近代化(20%)
  - **技術分野**: ネットワーク・IAM・データベース・可用性/DR・コスト最適化 など14分野
- **🔁 まちがい復習** — 直近で不正解だった問題だけを集めて再挑戦。正解すると習得へ進む。
- **⏱️ 模擬試験** — 本番形式 75問/180分、またはハーフ模試 40問/95分。
  出題比率は本番のドメイン配分どおり。解答中は正誤を出さず、最後にまとめて採点する。
  1000点満点換算のスコア目安（合格ライン750点）とドメイン別正答率を表示。
  解答中は前後移動・🚩フラグ・進捗ドットからの問題ジャンプができる。
- **🃏 フラッシュカード** — タップで表⇄裏。サービスの使い分けの暗記・復習向け。

### 進捗のしくみ

- **試験日カウントダウン** — ホームに「あと◯日」と、残り問題数から逆算した1日あたりのペース。
- **デイリー目標** — 1日の目標問題数（既定20問）に対する達成リングと、🔥連続学習日数。
- **習得判定** — 問題ごとに Leitner 方式のボックスを持ち、**連続3回正解で「習得ずみ」**。
  不正解になるとボックスは0に戻り、「まちがい復習」の対象になる。
- **📊 進捗と設定** — 全体／ドメイン別／技術分野別の到達度（習得ずみ・学習中・要復習・未着手）、
  直近14日の学習量グラフ、模擬試験の履歴。試験日と1日の目標問題数もここで変更できる。

記録は **この端末の `localStorage`** にのみ保存される（サーバー送信なし）。
「学習データをすべて消す」でリセットできる。

### 収録内容

全**202問** / 4ドメイン / 14分野。

| ドメイン | 問題数 | 本番比率 |
| --- | --- | --- |
| 組織の複雑さに対応する設計 | 54問 | 26% |
| 新しいソリューションのための設計 | 59問 | 29% |
| 既存ソリューションの継続的な改善 | 49問 | 25% |
| ワークロードの移行とモダナイゼーション | 40問 | 20% |

- 短文の知識確認と、本番同様の長文シナリオ問題のミックス。
- 単一選択に加えて、**複数選択（2つ選ぶ）問題を28問**収録（本番同様の形式）。
- 全問に解説付き。誤答の選択肢がなぜ違うのかにも触れている。
- 一部の問題は解説にSVG図解付き（SCP の継承・DR 戦略の比較・TGW とピアリング・
  ハイブリッド DNS・S3 ストレージクラス・クロスアカウントの AssumeRole）。
- このうち30問は `SAP-C02-quiz.md`（自作の練習問題集）から取り込んだもの（id が `md-` で始まる）。

## 動かし方

ビルド不要。`index.html` をブラウザで開くだけ（`questions.js` を読むので、
ローカルで開くときも同じフォルダごと開くこと）。
GitHub Pages のランチャー（My Apps）には「AWS SAP 対策」として掲載。

### iPhone にインストール

`manifest.json` + `sw.js` を持つ PWA なので、Safari で開いて
「共有 → ホーム画面に追加」するとフルスクリーンのアプリとして起動し、
**オフラインでも動く**（通勤中など電波の悪い場所での学習向け）。
