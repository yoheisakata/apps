# ♞ チェス

ブラウザだけで遊べるチェスアプリ。ビルド不要・依存ライブラリなしの単一 HTML ファイル。

## 遊び方

- ホーム画面で「対AI対戦」か「2人対戦」を選ぶ
- 対AI対戦では、白/黒と強さ(やさしい/ふつう/つよい)を選べる(黒を選ぶと盤面が反転し、自分の駒が下側に表示される)
- 盤上の駒をタップして選択 → 移動先(青い印)をタップで動かす
- ポーンが最終段に到達すると、昇格する駒(クイーン/ルーク/ビショップ/ナイト)を選択するモーダルが出る
- キャスリング(お城)は、王をタップして2マス先(城の完成位置)をタップすると自動で行われる(条件を満たす場合のみ移動先として表示される)
- アンパッサン(相手が直前に2マス進めたポーンを、通過したマスで斜めに取る)にも対応
- チェックのときは盤上の王のマスが赤く表示され、メッセージが出る
- チェックメイト、またはステイルメイト(引き分け)になると結果が表示される
- 取った駒は盤の上下に一覧表示される

## ルール実装メモ

- 全6種類の駒の動き、キャスリング(両側、通過マス/着地マスが攻撃されていないことを含む全条件)、アンパッサン、プロモーションに対応
- スリーフォールド・レペティション(同一局面3回での引き分け)、50手ルール、駒不足による引き分けは簡略化のため未実装(手数カウンタ自体は内部で保持しているが、判定には使っていない)

## 技術メモ

- `index.html` 単体で完結(インライン CSS/JS)、ビルドステップなし
- AI は簡易ネガマックス + αβ枝刈り。やさしい=1手、ふつう=2手、つよい=3手先読み。持ち駒がない分だけ将棋アプリより探索コストが低いため、将棋(1〜2手)より1手深く読ませている(Node での計測で3手読みの最大応答時間は約200ms、詳細は `CLAUDE.md` 参照)
