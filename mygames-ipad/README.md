# MyGames Pad

iPad用のボードゲーム&トランプゲーム集。MyGames(Mac版)のNES/SNESエミュレータ機能
(ライブラリ/ROM/コントローラー)は含みません。トップメニューは黒背景の
1つのグリッドに、将棋・チェス・オセロ・囲碁・五目並べ・ダイヤモンドゲーム・
チェッカー・コネクトフォーの8種と、トランプの8種(神経衰弱・ババ抜き・スピード・
大富豪・７並べ・21・ポーカー・ブラックジャック)、合計16個が同じアイコンの
並びで表示されます(タブや上下分割はなく、全16個が対等な1つのグループです)。

## 使い方

### ボードゲーム

全8種とも「対戦相手」で AI対戦/2人対戦 を切り替えられます。

1. トップメニューでアイコンをタップするとセットアップ画面が開く
   (盤面はまだ見えない、フルスクリーン表示に切り替わる)。
   「vs CPU」/「2人対戦」をラジオボタンで選び(vs CPUのときはAIの強さなども
   選べる)、「スタート」を押すと対局が始まる。
   - **vs CPUは横向き固定、2人対戦は縦向き固定**で画面が回転する
   (タブレットを挟んで向かい合う2人対戦を想定)。セットアップ画面自体は
   どちらの向きでも操作できる。
2. 2回目以降にアイコンをタップすると、対局の続きから再開する。ゲーム画面の
   「設定を変える」ボタンでセットアップ画面に戻り、設定を選び直せる。
3. 各ゲーム画面には「途中保存」欄があり、3スロットへの保存・読み込みができる。
4. 画面左上の「その他のゲーム」でいつでも一覧に戻れる(画面の向きの固定も
   解除される)。

チェッカーは相手を飛び越えて取れるときは必ず取らなければならない捕獲優先
ルールで、連続して取れるときはそのまま続けて取ります。コネクトフォーは
列をタップすると一番下の空きマスに落ち、縦・横・斜めに4つ並べたら勝ちです。

### トランプ

トップメニューでトランプのアイコン(神経衰弱・ババ抜き・スピード・大富豪・
７並べ・21・ポーカー・ブラックジャック)をタップすると、そのゲームの設定画面
(対AI対戦/2人対戦など)がフルスクリーンで直接開きます(トランプのホーム画面を
経由しません)。設定を選んで対局を始めます(Web版「トランプゲーム」=
`pwa/cardgames/`と同じ内容をそのまま表示)。ルール・対応状況はWeb版と同じ
(既知の簡略化は`pwa/cardgames/CLAUDE.md`参照)。画面左上の「その他のゲーム」で
一覧に戻れます。

> **「My Mac (Designed for iPad)」実行先では動作しません**: `WKWebView`が
> `WebContentProcess`を起動できずトランプ画面が読み込めないという既知の
> macOS側の制約があります(ローカルビルドのiPadアプリをMacのウィンドウとして
> 動かすモード特有の問題)。実iPad、またはXcodeのiOSシミュレータで実行してください。

## インストール(無料Apple IDでの7日間運用)

Apple Developer Programに入っていない場合、無料のApple IDでもXcodeから実機に
インストールできますが、**7日ごとに再インストールが必要**です。

1. `mygames-ipad`フォルダをMacで開き、ターミナルで以下を実行してXcode
   プロジェクトを生成します(初回、および`project.yml`を変更した後は毎回必要):
   ```bash
   xcodegen generate
   open MyGamesPad.xcodeproj
   ```
2. XcodeでSigning & Capabilities → Teamに自分のApple ID(Personal Team)を選択します。
3. iPadをUSBでMacに接続し、実行先(destination)にそのiPadを選んで▶を押すと
   インストールされます。
4. 7日経つと起動できなくなるので、同じ手順で再インストールしてください。

## 制限事項

- NES/SNESエミュレーション機能(ライブラリ/ROM/コントローラー設定)は非対応。
- 対局の保存はアプリ内蔵ストレージのみ(端末間の同期なし)。
