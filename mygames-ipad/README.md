# MyGames Pad

iPad用のボードゲーム&トランプゲーム集。MyGames(Mac版)のNES/SNESエミュレータ機能
(ライブラリ/ROM/コントローラー)は含みません。画面上部のタブで「ボードゲーム」/
「トランプ」を切り替えます。

## 使い方

### ボードゲーム

将棋・チェス・オセロ・囲碁・五目並べ・麻雀・ダイヤモンドゲームの7種。
麻雀以外の6種は「対戦相手」で AI対戦/2人対戦 を切り替えられます(麻雀は
4人前提のゲームのため1人プレイ vs AI×3のみ)。MyGames(Mac版)の
「ボードゲーム」タブをそのまま移植したものです。

1. メニュー画面で7種のゲームがアイコンで並ぶ。
2. アイコンをタップすると新規対局が始まる(2回目以降は続きから)。
3. 「対局」欄の「対戦相手」ピッカーでAI対戦(強さも選べる)/2人対戦を選ぶ。
   2人対戦では同じiPadを回しながら交互にタップして指します。
4. 各ゲーム画面には「途中保存」欄があり、3スロットへの保存・読み込みができる。
5. 画面左上の「メニュー」でいつでも一覧に戻れる。

ルール・対応状況はMac版と同じ(各ゲームの既知の簡略化はMac版`mygames/CLAUDE.md`
参照)。

### トランプ

神経衰弱・ババ抜き・スピード・大富豪・７並べ・21・ポーカー・ブラックジャックの
8種(Web版「トランプゲーム」= `pwa/cardgames/`と同じ内容をそのまま表示)。
ホーム画面のアイコンから各ゲームを選び、設定画面(対AI対戦/2人対戦など)を
経て対局を始めます。ルール・対応状況はWeb版と同じ(既知の簡略化は
`pwa/cardgames/CLAUDE.md`参照)。

## インストール(無料Apple IDでの7日間運用)

Apple Developer Programに入っていない場合、無料のApple IDでもXcodeから実機に
インストールできますが、**7日ごとに再インストールが必要**です。

1. `mygames-ipad`フォルダをMacで開き、ターミナルで以下を実行してXcode
   プロジェクトを生成します(初回、および`project.yml`を変更した後は毎回必要):
   ```bash
   xcodegen generate
   open MyGamesPad.xcodeproj
   ```
2. XcodeでSigning & Capabilities → Teamに自分のApple ID(Personal Team)を選択します。
3. iPadをUSBでMacに接続し、実行先(destination)にそのiPadを選んで▶を押すと
   インストールされます。
4. 7日経つと起動できなくなるので、同じ手順で再インストールしてください。

## 制限事項

- NES/SNESエミュレーション機能(ライブラリ/ROM/コントローラー設定)は非対応。
- 対局の保存はアプリ内蔵ストレージのみ(端末間の同期なし)。
