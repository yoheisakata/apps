# MySlideshow Pad

iPad用のスライドショーアプリ。**OneDriveの共有リンクだけ**を対象にした、旧myslideshow(Mac版)の
縮小版として作られました。ローカルフォルダには対応していません(そもそもMac版もOneDrive共有
リンク専用)。**Mac版は2026-09-02に廃止され、同等の機能はMyGalleryに統合されています**
(`mygallery/CLAUDE.md`参照)。このiPad版はその影響を受けず、そのまま独立して動作します。

## 使い方

1. アプリを起動すると、ホーム画面が開く。OneDriveリンクは2件(動画専用「動画」・写真専用
   「写真」、追加・削除はできない ― 下記「リンクについて」参照)。それぞれの年別チェックリスト
   (「動画」は2020〜2021年、「写真」は2020〜2026年、決め打ち)が起動直後から即座に出る
   (この時点ではOneDriveへはまだアクセスしない)。
2. 対象にしたい年をチップ状のボタンでタップして選ぶ(選択中は青く塗りつぶされる)。選んだ年は
   リンクごとに次回も同じ選択で開く。各グループに「全選択」/「全非選択」ボタンもある。
3. 写真の表示秒数・シャッフル・時間制限をこの画面で設定し、「スライドショー開始」を押すと、
   選んだ年に該当する動画・写真をそのタイミングで初めてOneDriveへ取得しに行く(少し待つことが
   ある)。取得できた分をフルスクリーンで自動再生し始める。
   - 写真は一定秒数(既定6秒)表示したら次へ進む。
   - 動画は最後まで再生してから次へ進む。
   - 操作は不要 ― 画面をタップすると下部に一時停止/前後送り/終了ボタンが3秒だけ現れる。
   - Magic Keyboard等の外部キーボードを接続していれば、スペース(一時停止/再開)、←→
     (前後の写真・動画へ)、esc(終了してホーム画面へ戻る)でも操作できる。

## リンクについて

OneDriveリンクはアプリのコードに直書きされた固定の2件だけで、アプリ内から追加・削除する
画面は無い(リンクはめったに変わらないため)。年別チェックボックスの選択肢もコードに決め打ちで、
OneDriveをスキャンして動的に取得することはしない(実際にOneDriveへ取得しに行くのは
「スライドショー開始」を押した瞬間だけ)。リンク自体や年の範囲を変える・増やす場合は
`ContentView.swift`の`links`配列を直接編集する。

## 日付表示

ファイル名から撮影日を推測できたときは、画面右下に「2023年5月15日」のように小さく表示する
(`IMG_20230515_120033.jpg`のような、カメラ・スマホの標準的な命名規則が対象)。

## 時間制限

スライダーで、スライドショーの最大再生時間を5分刻みで5分〜60分の間に設定できる。右端まで
動かすと「無制限」(既定)になる。制限時間に達すると自動的にスライドショーを終了してホーム画面へ
戻る。

## 制限事項

- OneDriveの「リンクを知っている全員が閲覧可能」な共有リンクのみ対応。
- ローカルフォルダの読み込みには対応していない(OneDrive共有リンク専用)。
- スキャンは選んだ年フォルダだけを辿るが、階層が非常に深い・フォルダ数が非常に多いライブラリで
  多くの年を選んでいる場合は、開始してから実際に始まるまで時間がかかることがある。
- OneDriveの署名付きダウンロードURLは1時間程度で失効するが、スキャンは「スライドショー開始」を
  押すたびに毎回行うため、通常は気にしなくてよい。

## インストール(無料Apple IDでの7日間運用)

Apple Developer Programに入っていない場合、無料のApple IDでもXcodeから実機にインストール
できますが、**7日ごとに再インストールが必要**です。

1. `myslideshow-ipad`フォルダをMacで開き、ターミナルで以下を実行してXcodeプロジェクトを
   生成します(初回、および`project.yml`を変更した後は毎回必要):
   ```bash
   xcodegen generate
   open MySlideshowPad.xcodeproj
   ```
2. XcodeでSigning & Capabilities → Teamに自分のApple ID(Personal Team)を選択します。
3. iPadをUSBでMacに接続し、実行先(destination)にそのiPadを選んで▶を押すとインストールされます。
4. 7日経つと起動できなくなるので、同じ手順で再インストールしてください。

## 制約

- OneDriveの非公式内部API(`api-badgerp.svc.ms`)を使っています。Microsoftが予告なく仕様変更・
  遮断する可能性があります。
