# PassMan 🔑

macOS 用のシンプルなパスワード管理アプリ（SwiftUI 製ネイティブ GUI）。
サービスのログイン情報をカテゴリ分けして保存し、マスターパスワード 1 つで
まとめて暗号化・管理できます。

> ⚠️ ネイティブ macOS アプリのため GitHub Pages では動きません
> （networth / cleanmac などと同じローカルビルドのツール群です）。

## 特長 / セキュリティ設計

- **すべて暗号化して保存**。vault 全体をランダムなデータ鍵（DEK）で
  **AES-256-GCM** 暗号化し、その鍵をマスターパスワード由来の鍵で包んで保管します
  （エンベロープ暗号化）。マスターパスワードはどこにも保存しません。
- 鍵導出は **PBKDF2-HMAC-SHA256（60 万回）**。外部ライブラリ非依存、Apple の
  システムフレームワーク（CryptoKit）だけで完結します。
- パスワードのコピーは **30 秒で自動的にクリップボードから消去**。履歴アプリに
  残らないよう Concealed/Transient マークも付けます。
- **自動ロック**（無操作 N 分）と**バックグラウンド移行時のロック**に対応。
- データも秘密情報もリポジトリには入りません（下記「データの置き場所」参照）。

## 機能

### エントリー管理
- タイトル / カテゴリ / ログイン名 / パスワード / ヒント / URL / メモ を保存
- ログイン名・パスワードのワンクリックコピー、パスワードの表示/非表示切り替え
- タイトル・ログイン名・URL で絞り込む検索

### カテゴリ
- 初期カテゴリ（Web / メール / 金融 / SNS / 仕事 / ショッピング / その他）付き
- サイドバー下部の「カテゴリを追加」から**自分でカテゴリを追加**（名前 + アイコン 28 種）
- 右クリックの「削除」で**カテゴリを削除**（「その他」は削除不可。削除したカテゴリの
  エントリーは「その他」に移動）

### ロック解除の 4 段階
1. **マスターパスワード** — 通常の解除方法
2. **Touch ID（指紋）** — 設定でオンにすると日常の解除を指紋で。
   パスワードを変更しても有効なまま
3. **リカバリーキー** — マスターパスワードを忘れたとき用。vault 作成時に一度だけ
   表示される 25 文字のキー（例 `MVHHK-RHJA6-ANC24-XBDPW-EG9MQ`）。
   解除後は新しいマスターパスワードの設定を求められます
4. **初期化** — マスターパスワードもリカバリーキーも失った場合の最終手段。
   確認語「初期化」の入力を必須にした上で、vault を完全削除して作り直します
   （**保存データはすべて失われます**）

> #### Touch ID についての注意
> このアプリはローカルの ad-hoc 署名（Apple Developer Team なし）のため、
> Secure Enclave 連動の生体認証キーチェーンは entitlement 不足で使えません。
> そのため DEK は通常のログインキーチェーン（この端末のみ・iCloud 非同期）に保存し、
> 取り出し前に Touch ID を必須化する **アプリレベルのゲート**として実装しています。
> 強固な保護経路はマスターパスワードとリカバリーキーが担います。

## データの置き場所

| データ | 保存先 |
|--------|--------|
| vault 本体（暗号化済み） | `~/Library/Application Support/PassMan/vault.dat` |
| Touch ID 用のデータ鍵 | **Keychain**（ログインキーチェーン、この端末のみ） |
| 旧フォーマットからの移行バックアップ | `~/Library/Application Support/PassMan/vault.pmv1.bak` |

## ビルドとインストール

```bash
cd passman
swift run           # 開発ビルド（ウィンドウ起動）
./build_app.sh      # release ビルド + ad-hoc 署名 → PassMan.app
./install.sh        # ビルド → /Applications へコピー → 起動
```

アイコンは `swift make-icon.swift` で再生成（networth と同じ紫グラデ背景 +
白い鍵穴シルエット）。

## 初回の使い方

1. 起動して**マスターパスワードを設定**（8 文字以上）
2. 直後に表示される**リカバリーキーを必ず控える**（紙などに書き写す。
   この画面を閉じると二度と表示されません）
3. 「＋」からエントリーを追加。必要に応じてカテゴリも追加
4. （任意）設定（⚙）→「Touch IDで解除」をオンにすると、次回から指紋で解除できます

## ファイル形式について

vault は現行の **PMV2**（JSON エンベロープ暗号化）で保存されます。ごく初期に作成した
**PMV1**（バイナリ）の vault は、マスターパスワードで初めて解除したときに自動で
PMV2 へ移行し、その際にリカバリーキーが一度だけ発行されます（移行前ファイルは
`vault.pmv1.bak` に自動退避）。
