# 💎 ダイヤモンドゲーム

ブラウザだけで遊べるダイヤモンドゲーム(中国式チェッカー/ハルマの日本版、星型の盤で遊ぶ定番ボードゲーム)アプリ。ビルド不要・依存ライブラリなしの単一 HTML ファイル。

## 遊び方

- ホーム画面で「対AI対戦」か「2人対戦」を選ぶ
- 対AI対戦では、先攻/後攻と強さ(やさしい/ふつう/つよい)を選べる
- 自分の駒をタップして選択 → 移動先(青くハイライトされた穴)をタップで進める
- 1回の手番では、①隣の空いている穴に1マス進める、②駒を飛び越えてジャンプする(何度でも連続可)、のどちらか一方だけを行える(1マス移動とジャンプを同じ手番で混ぜることはできない)
- 自分の10個の駒をすべて、盤の反対側にある先端(6穴×… ではなく10穴の三角形)に移動させたら勝ち
- 動かせる駒が1つもない場合は自動的に手番が相手に渡る(メッセージで通知)

## ルール実装メモ

- ジャンプは駒の所有者を問わない(自分の駒・相手の駒どちらを飛び越えてもよい)。チェッカーと違い、飛び越えられた駒が取られることはない(捕獲のないレースゲーム)
- 連続ジャンプ(チェーンジャンプ)は、同じ手番の中で同じ穴に二度着地することはできない、というルールに対応(無限ループの防止も兼ねる)
- 勝利条件は「自分の出発地点と正反対にある先端の10穴すべてを自分の駒で埋める」こと
- 2人対戦のみ実装(4人・6人対戦は今回は未実装 — 詳細は `CLAUDE.md` 参照)

## 技術メモ

- `index.html` 単体で完結(インライン CSS/JS)、ビルドステップなし
- 盤面は cube 座標系 (x,y,z, x+y+z=0) で管理し、SVG で描画(六角形グリッドは正方形マスに無理やり収めると形状やジャンプの直線判定が複雑になるため)
- AI は簡易ネガマックス + αβ枝刈り(1〜2手読み)。評価関数は「駒がゴール方向へどれだけ進んだか」の合計(捕獲がないレースゲームのため、進み具合だけで十分機能する)
