# ♟️ 将棋

ブラウザだけで遊べる将棋アプリ。ビルド不要・依存ライブラリなしの単一 HTML ファイル。

## 遊び方

- ホーム画面で「対AI対戦」か「2人対戦」を選ぶ
- 対AI対戦では、先手/後手と強さ(やさしい/ふつう/つよい)を選べる
- 盤上の駒をタップして選択 → 移動先(青い印)をタップで指す
- 持ち駒は盤の上下に表示され、タップして選択 → 盤上の空きマスをタップで打てる
- 成れるマスに進んだときは「成る/成らない」を選択(強制成りの場合は自動で成る)
- 詰み(または手なし)になると勝敗が表示される

## ルール実装メモ

- 二歩・行き所のない駒(歩・香の最終段、桂の最終2段)の禁止に対応
- 打ち歩詰め(打った歩による詰み)の禁止は簡略化のため未実装
- 千日手(同一局面の反復)の判定は未実装

## 技術メモ

- `index.html` 単体で完結(インライン CSS/JS)、ビルドステップなし
- AI は簡易ネガマックス + αβ枝刈り(1〜2手読み)。持ち駒を含む合法手生成のコストが高いため、探索深さは意図的に浅く抑えている
