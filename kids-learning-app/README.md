# まなびアプリ 🌟 — `kids-learning-app/`

子ども向けの学習アプリ（Webアプリ・PWA）。

## 機能

- **たしざん** — レベル1〜5から選んで、絵文字による数の視覚化つき3択クイズに挑戦。
- **かけざん（くく）** — 段（だん）を選んで九九を順に覚える学習カード。
  Web Speech API（`speechSynthesis`）による読み上げつき。
  「🔊 もういちど きく」で発音を聞き直せる。
- **ひらがな(なぞりがき)** — 行を選んで、うすく表示されたお手本の文字を
  指やマウスでなぞる練習。8割以上なぞれると自動で正解になり、次の文字へ進む。
- **タイピング** — ひらがな1文字/かんたんなことばをローマ字入力で練習。
- 正解すると⭐スターがたまる（`localStorage` に保存）。

## 動かし方

ビルド不要の複数ファイル構成（`index.html` + `app.js` + `style.css`）。
`index.html` をブラウザで開くだけ。オフラインでも使えるよう Service Worker
（`sw.js`）でキャッシュしている。

GitHub Pages のランチャー（My Apps）には「まなびアプリ」として掲載されている。
