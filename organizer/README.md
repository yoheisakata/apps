# Organizer 🗂️ — `organizer/`

`utilities/` の写真・動画バックアップパイプライン(6スクリプト)と、旧`renamer/`アプリの
一括リネーム機能、旧`cleanmac/`アプリのキャッシュ掃除・アプリのアンインストール機能、
旧`omoide/`アプリのまとめ動画作成機能を1つのGUIにまとめたmacOSネイティブ
アプリ。**SwiftUI + SPM** 構成。

## 機能

サイドバーの13ペイン + 依存チェック:

| ペイン | 内容 | 相当するutilities/旧アプリ |
|---|---|---|
| リネーム | ルールベースの一括ファイル名変更（検索置換・連番・日付・メタデータ挿入等）。プレビュー確認→衝突チェック→実行、複数回のUndo、履歴ログ | 旧`renamer/`アプリ |
| 写真整理 | Photos書き出し済み写真を撮影日時フォルダに整理・HEIC→JPG変換 | `backup-photos.sh` |
| 動画整理 | Photos書き出し済み動画を撮影日時フォルダに整理。移動が終わったファイルから順にH.265エンコードも実行（デフォルトON、「エンコードしない」で無効化可） | `backup-videos.sh` |
| エンコード | 任意フォルダの動画をH.265(HEVC)+mp4に統一。「スキャン」ボタンでエンコードを実行せずに、あと何件・何GB分の動画がエンコード待ちかを事前確認できる。実行中は「全体の進捗」バーでエンコード対象件数のうち何件終わったか・残り時間の目安も表示 | `encode_h265.py` |
| 誤配置修正 | 整理済みフォルダの構造・ファイル名を年単位/月単位で検証・修正（類似写真からの日付推定つき） | `verify-photos.sh` |
| 日付推定 | 撮影日が分からない写真を、候補年の写真と顔検出+画像特徴量で見た目比較し、候補日付を提示（人が選んで確定） | (新規) |
| 同期 | 2つのHDD間でrsyncミラーリング（差分確認→確認ダイアログ→実行） | `sync-backups.sh` |
| 短い動画検索 | 指定秒数以下の動画を洗い出し、レポート/M3U出力 | `find_short_videos.py` |
| クリーン | `~/Library/Caches`・ログ・ゴミ箱・Xcode関連に加え、ホームディレクトリ内の`.DS_Store`・`._*`（AppleDouble）といった不要な隠しファイルをスキャンしてゴミ箱へ移動 | 旧`cleanmac/`アプリ |
| アプリ削除 | `/Applications`のアプリ一覧・サイズ表示、関連ファイル（設定・キャッシュ等）ごとゴミ箱へ移動 | 旧`cleanmac/`アプリ |
| 動画重複 | ファイル名・長さ・フレームハッシュから重複動画を検出し、選んだ1本以外をゴミ箱へ移動 | (新規) |
| まとめ動画 | 子ども動画のフォルダから短いクリップを抜き出してつなぎ、タイトルカード・BGMを合成した1本のまとめ動画を作成 | 旧`omoide/`アプリ |

日付推定（EXIF/QuickTime→コンテンツ作成日→フォルダ名→ファイル名→更新日時の5段階
フォールバック）・MD5重複判定・rsync差分パース等のロジックはSwiftネイティブで再実装
している（`utilities/`のスクリプトは呼び出さない、独立した実装）。`ffmpeg` / `ffprobe` /
`rsync` / `sips` / `mdls` は外部コマンドとしてそのまま呼び出す（同梱しない）。

## 動かし方

```bash
swift run                        # 開発ビルド（ウィンドウ起動）
./build_app.sh                   # release ビルド → Organizer.app
./install.sh                     # ビルド → /Applications へインストール
```

`ffmpeg` / `ffprobe`（動画エンコード・同期以外の機能では不要）、`rsync`（同期機能のみ、
Homebrew版推奨・日本語ファイル名対応）が必要です。アプリ内の「依存チェック」ペインで
インストール状況を確認できます。

```bash
brew install ffmpeg
```

## 注意

- 「同期」ペインはターゲット側にしかないファイルを削除します。必ず「差分を確認」で
  内容を見てから実行してください（確認ダイアログでも件数を表示します）。
- アプリ全体でジョブは同時に1本まで。進捗・詳細・ログは共通の「実行ログ」ウィンドウ
  （ジョブ開始時に自動で開く。ツールバーのボタンからも開ける）に集約されます。
  下部のステータスバーにはタイトル・進捗%・中止ボタンだけ表示されます。
  「リネーム」ペインはリネームが同期的で一瞬のため、このジョブ/ログの仕組みは使わず
  旧`renamer/`アプリと同じ即時プレビュー+実行ボタンのUIのままです。
- 「クリーン」「アプリ削除」ペインの削除は必ず「ゴミ箱へ移動」
  （完全削除はしないため、ゴミ箱を空にするまで復元できます）。対象はユーザー領域のみ
  （`/System`等のシステム領域は対象外）。実行前に必ずスキャン→サイズ表示→選択→
  確認ダイアログを挟みます。
- 「アプリ削除」でApp Store製など通常の方法で削除できないアプリを扱う場合、Finder経由
  （AppleScript）で再試行します。初回は「OrganizerがFinderを制御しようとしています」
  という許可ダイアログが出ます（システム設定 › プライバシーとセキュリティ ›
  オートメーション で確認・変更可）。
- 一部のキャッシュフォルダのスキャンには**フルディスクアクセス**が必要な場合があります。
