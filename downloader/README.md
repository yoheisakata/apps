# Downloader

YouTube の動画・音声ダウンロードと、magnet リンク / .torrent ファイルのダウンロードを
1つにまとめた macOS アプリ(旧 `youtube-dl-mac` + `torrent-dl-mac` の統合版)。
ウィンドウ上部のタブで「YouTube」「Torrent」を切り替える。

## 事前準備

どちらの機能も内部で既存の CLI ツールに処理を任せている。Homebrew で未インストールなら
ターミナルで以下を実行する。

```bash
brew install yt-dlp ffmpeg aria2
```

- **yt-dlp**: YouTube のダウンロード本体。仕様変更に追従するため定期的に `brew upgrade yt-dlp` すること。
- **ffmpeg**: 音声・映像の変換/結合。
- **aria2**: torrent/magnet のダウンロードエンジン(`aria2c` を JSON-RPC 経由で操作)。

各タブとも、対応するツールが見つからない間はオレンジ色のバナーが表示され、操作が無効になる。

## 使い方

起動すると Dock アイコンが表示され、ウィンドウが自動で開く(メニューバーにも ⬇️ アイコンが
出るので、ウィンドウを閉じたあとはそこから、または Dock アイコンをクリックして呼び戻せる)。
ウィンドウを閉じてもダウンロードは中断されず、Dock アイコン右クリックまたはメニューバー
アイコンの「終了」を選ぶまで動き続ける。

### YouTube タブ

- リンクを貼り付け、Audio(mp3・最高音質)/ Video(mp4、画質選択可、最大4K)をチェックしてダウンロード
- 保存先フォルダを選択可能(既定は `~/Downloads`)
- プレイリストのURL(`list=`を含む)を貼り付けると「プレイリスト全体をダウンロード」が自動でON
  になる(手動でも切り替え可)。ONの場合、`保存先/ダウンロード名/` にまとめて保存される
  ―そのままそのフォルダを mytube で「フォルダを選択」して開けば、プレイリストとして閲覧できる。
- リンクを貼り付けると「ダウンロード名」欄に動画/プレイリストのタイトルが自動取得される
  (取得中はスピナー表示)。そのまま使うほか、自由に書き換えて保存先フォルダ名/ファイル名を
  上書きできる。取得に失敗しても手入力すればダウンロードは続行できる。「/」等ファイル名に
  使えない文字が含まれる場合は注意文が表示され、実際の保存時は自動的に置き換えられる。
- 進捗バーと yt-dlp の生ログを表示、中止ボタンあり(プレイリストダウンロード中は
  「(3/23) …」のように全体の何本目かも表示される)

### Torrent タブ

- **追加**: ツールバーの「追加」から magnet リンクを貼り付けるか、「ファイルを選択…」で `.torrent` を選ぶ。
  ウィンドウに `.torrent` ファイルをドラッグ&ドロップしても追加できる。
- **一覧**: 各項目に進捗バー・ダウンロード/アップロード速度・シード比率(ratio)を表示。
  「一時停止」「再開」「削除」が個別に行える。
- **ブラウザの magnet リンクをクリックして起動**できる。アプリが `magnet:` スキームのハンドラとして登録される
  (`./install.sh` で `/Applications` に入れて一度起動すると Launch Services に認識される)。
  ブラウザによっては初回に「このアプリで開きますか?」という確認が出るので許可する。
  アプリが未起動でもクリックで自動起動し、そのままダウンロードが始まる。
- ツールバーの「設定」から帯域制限・保存先・シード設定を変更できる:

  | 項目 | 説明 | 反映方法 |
  |---|---|---|
  | アップロード上限 (KB/s) | 0 で無制限。デフォルトは 50 KB/s | 即時反映 |
  | ダウンロード上限 (KB/s) | 0 で無制限(デフォルト) | 即時反映 |
  | 保存先フォルダ | デフォルトは `~/Downloads/Torrents` | 「保存して再起動」が必要 |
  | Seed ratio 上限 | ダウンロード完了後、この比率に達したらシード停止。デフォルト 0(即停止) | 「保存して再起動」が必要 |
  | Seed time 上限(分) | ダウンロード完了後、この時間が経過したらシード停止。デフォルト 0(即停止) | 「保存して再起動」が必要 |

  デフォルト設定(アップロード上限 50 KB/s・seed ratio/time 0)が
  「目一杯ダウンロードするが、アップロードはほとんどしない」という挙動になる。

### 共通

- **ウィンドウを閉じてもダウンロードは継続**する(YouTube・Torrent いずれも)。
  メニューバーアイコンから「ウィンドウを開く」でいつでも戻れる。
  完全に終了するにはメニューバーの「終了」を選ぶ。

## インストール

```bash
cd downloader
./install.sh
```

`/Applications/Downloader.app` に上書きインストールされる。旧 `YouTube-downloader.app` /
`Torrent-downloader.app` が `/Applications` に残っている場合は、`magnet:` リンクの登録が
競合しないよう手動で削除しておくこと。

## 注意

- YouTube のダウンロードは利用規約および著作権法の範囲内(自分のコンテンツ・権利者の許諾があるもの・
  パブリックドメイン等)で利用すること。
- torrent 技術自体は合法だが、著作権のあるコンテンツを権利者の許可なく取得・共有することは
  違法になり得る。自分に権利がある、またはパブリックドメイン/配布許可のあるファイルにのみ使用すること。
