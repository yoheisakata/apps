# Downloader

YouTube の動画・音声をダウンロードする macOS アプリ(旧 `youtube-dl-mac`)。

> 以前は magnet / .torrent をダウンロードする「Torrent」タブ(`aria2c` ラッパー、旧 `torrent-dl-mac`)も
> 持っていたが、2026-08-12 に torrent 機能は削除した。`aria2` はこのアプリの動作には不要になっている。

## 事前準備

ダウンロード処理は既存の CLI ツールに任せている。Homebrew で未インストールなら
ターミナルで以下を実行する。

```bash
brew install yt-dlp ffmpeg
```

- **yt-dlp**: YouTube のダウンロード本体。仕様変更に追従するため定期的に `brew upgrade yt-dlp` すること。
- **ffmpeg**: 音声・映像の変換/結合。

ツールが見つからない間はオレンジ色のバナーが表示され、操作が無効になる。

## 使い方

起動すると Dock アイコンが表示され、ウィンドウが自動で開く(メニューバーにも ⬇️ アイコンが
出るので、ウィンドウを閉じたあとはそこから、または Dock アイコンをクリックして呼び戻せる)。
ウィンドウを閉じてもダウンロードは中断されず、Dock アイコン右クリックまたはメニューバー
アイコンの「終了」を選ぶまで動き続ける。

- リンクを貼り付け、Audio(mp3・最高音質)/ Video(mp4、画質選択可、最大4K)をチェックしてダウンロード
- 保存先フォルダを選択可能(既定は `~/Downloads`)
- プレイリストのURL(`list=`を含む)を貼り付けると「プレイリスト全体をダウンロード」が自動でON
  になる(手動でも切り替え可)。ONの場合、`保存先/ダウンロード名/` にまとめて保存される
  ―そのままそのフォルダを mytube で「フォルダを選択」して開けば、プレイリストとして閲覧できる。
- リンクを貼り付けると「ダウンロード名」欄に動画/プレイリストのタイトルが自動取得される
  (取得中はスピナー表示)。そのまま使うほか、自由に書き換えて保存先フォルダ名/ファイル名を
  上書きできる。取得に失敗しても手入力すればダウンロードは続行できる。「/」等ファイル名に
  使えない文字が含まれる場合は注意文が表示され、実際の保存時は自動的に置き換えられる。
- 進捗バーと yt-dlp の生ログを表示、中止ボタンあり(プレイリストダウンロード中は
  「(3/23) …」のように全体の何本目かも表示される)
- **ウィンドウを閉じてもダウンロードは継続**する。メニューバーアイコンから「ウィンドウを開く」で
  いつでも戻れる。完全に終了するにはメニューバーの「終了」を選ぶ。

## インストール

```bash
cd downloader
./install.sh
```

`/Applications/MyApplications/Downloader.app` に上書きインストールされる。

torrent 機能を使っていた頃のデータ(`~/Library/Application Support/Downloader/session.aria2`、
`app.log`)は残っていても害はないが、不要なら削除してよい。`magnet:` リンクのハンドラ登録も
アプリからは無くなっている ― ブラウザがまだこのアプリを候補に出す場合は、Launch Services の
キャッシュが更新されるまで(または再ログインまで)残ることがある。

## 注意

- YouTube のダウンロードは利用規約および著作権法の範囲内(自分のコンテンツ・権利者の許諾があるもの・
  パブリックドメイン等)で利用すること。
