# くくをおぼえよう ✖️ — `kakeizan/`

5歳〜向けの九九（かけ算）学習アプリ（Webアプリ）。
段（だん）を選んで九九を順に覚えていく。読み上げ（音声合成）付きで、
「🔊 もういちど」で発音を聞き直せる。

## 機能

- 段ごとの学習（「つぎのだんへ」「ほかのだんをえらぶ」で移動）
- Web Speech API（`speechSynthesis`）による九九の読み上げ
- ひらがな中心の子ども向け UI

進行状況の保存は無い（開くたびに最初から。たしざんクエストと違い
`localStorage` は使っていない）。

## 動かし方

ビルド不要の単一 HTML ファイル。`index.html` をブラウザで開くだけ。
GitHub Pages のランチャー（アプリひろば）には「かけざんクエスト」として
掲載されている。
