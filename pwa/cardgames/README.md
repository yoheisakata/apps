# 🃏 トランプゲーム

ブラウザだけで遊べるトランプゲーム集。ビルド不要・依存ライブラリなしの単一 HTML ファイルで、複数のゲームをホーム画面から選んで遊べる。

収録ゲーム: 神経衰弱 / ババ抜き / スピード / 大富豪 / ７並べ / 21 / ポーカー / ブラックジャック の8種。

## 遊び方

ホーム画面でゲームを選ぶと、対戦相手(対AI対戦 / 2人対戦)などを選ぶセットアップ画面が出る。

### 🧠 神経衰弱

- カード枚数(24枚/52枚)を選んで開始。伏せられたカードを2枚めくり、同じランクなら自分の得点になりもう一度めくれる。外れると相手の番。
- 対AI対戦では CPU の「記憶力」(かんたん/ふつう/つよい)を選べる — 一度見えたカードを覚えている確率が変わる。
- 2人対戦は同じ端末で交互に操作する。

### 🃏 ババ抜き

- ジョーカーを1枚加えた53枚を全員に配り、最初に手札内のペアを自動で捨てる。
- 自分の番では、次のプレイヤーの伏せた手札から1枚タップして引く。ペアができれば自動で捨てられる。
- 最後までジョーカーを持っていたプレイヤーが負け。
- 対AI対戦は CPU 2人 or 3人と対戦。2人対戦は同じ端末で1対1。

### ⚡ スピード

- 手札5枚+山札を持ち、2つの場札に数字が1つ違うカードを次々出していく早出しゲーム。
- 手札のカードをタップして選択 → 出したい場札をタップ、で1枚出す。出すと山札から自動補充。
- 誰も出せなくなると、両者の山札から新しいカードが場に出て自動的に流れが再開する。
- 対AI対戦は CPU の速さ(ゆっくり/ふつう/はやい)を選べる。2人対戦は同じ端末で上下に分かれて同時に操作する(実質リアルタイム対戦なので広めの画面推奨)。

### 👑 大富豪

- ジョーカーを1枚加えた53枚を配り、3♦を持つプレイヤーから開始。手札から1枚、または同じランクを複数枚同時に出し、直前の場より強いランク(3〜2の順、ジョーカーが最強)を出していく。
- 出せなければ「パス」。全員がパスすると場が流れ、最後に出した人が自由に次を出せる(フリー)。
- 8を出すと「8切り」で場が流れ、同じ人がもう一度出せる。
- 対AI対戦は CPU 2人 or 3人。2人対戦は同じ端末で1対1。最初に手札がなくなった人から順に「大富豪」「富豪」…「大貧民」。

### 🔢 ７並べ

- 4スート×13ランクのボードに、7から順番につなげてカードを置いていく。7を持っていなければ他のカードは出せない。
- パスは自由(出せるカードがあっても任意にパス可能)。
- 対AI対戦は CPU 2人 or 3人。2人対戦は同じ端末で1対1。最初に手札がなくなった人が1位。

### 🎲 21

- ディーラーがいない多人数バーストゲーム。各プレイヤーが1枚のカードから始め、自分の番に「引く」を繰り返すか「止める」を選ぶ。21を超えたらバースト(失格)。
- 全員が止まる/バーストしたら、バーストしていない人の中で合計が一番大きい人の勝ち。
- 対AI対戦は CPU 2人 or 3人。2人対戦は同じ端末で1対1。

### ♠️ ポーカー

- ベットなしのファイブカードドロー。5枚配られた手札から交換したいカードを選び、「交換する」で1回だけ入れ替えられる(0枚でもOK)。
- 役(ワンペア〜ロイヤルストレートフラッシュ)を判定し、役が高い方が勝ち。同役ならキッカーで比較。
- 対AI対戦・2人対戦(同じ端末で手番を交代)。

### 🂡 ブラックジャック

- CPU ディーラー相手に、手札の合計を21に近づける。ヒット(引く)/スタンドのみ(ダブルダウン・スプリットなし)。
- ディーラーは合計17以上になるまで自動でヒットする。
- 対AI対戦は1人でディーラーと対戦。2人対戦は2人のプレイヤーが同じディーラーと同時に勝負する。

## 技術メモ

- `index.html` 単体で完結(インライン CSS/JS)、ビルドステップなし。
- カードのデータ構造・シャッフル・描画は全ゲーム共通のユーティリティ関数(`makeDeck`/`shuffle`/`cardHTML`/`backHTML`)を使い回している。
