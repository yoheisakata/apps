# ちきゅうをまなぼう 🌏 — `earth/`

地球や宇宙について遊びながら学べる、子ども向けのインタラクティブ地球儀
（Webアプリ）。Canvas に描いた地球をタップ・ドラッグで回せる。

## モード

| ボタン | 内容 |
|---|---|
| 🌏 | ちきゅうをまわそう — 自由に回して国をタップすると国旗・情報がポップアップ |
| 🌕 | 月の動き |
| 🚀 | 宇宙 |
| 🪐 | 太陽系 |

「まめちしき」（fact 表示）付きで、地球の大きさなどの豆知識が出る。

## 動かし方

ビルド不要の単一 HTML ファイル。`index.html` をブラウザで開くだけ。
