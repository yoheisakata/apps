# genaiquiz

単一の `index.html`(インライン CSS/JS、ビルド不要)。問題は `<script>` 内の配列 `Q`(`d`=ドメイン番号, `q`, `c`, `a`=正解index, `e`=解説)。

- 問題を足すだけならドメイン配列 `DOMAINS` と `Q` を編集。`a` は選択肢配列 `c` の添字(表示時に選択肢はシャッフルされる)。
- `localStorage` のキー `genaiquiz-v1` は問題のインデックスを保存している。**既存問題の順序を変えたり途中に挿入したりすると成績がずれる**ので、追加は各配列の末尾に行うか、キーを上げる。
- ドメイン名は暫定(配点は未記載)。公式試験ガイドで確認して直すこと。
- ファイルを変更したら `.app-version`(画面上部の `v1.0.0`)を同じコミットで上げる。
- v1.1.0 で10問を末尾に追加(動画は字幕取得不可のため、タイトルのテーマ=SageMaker データ/AIガバナンス・試験対策に沿った内容。動画本文の裏取りはしていない)。
- v1.2.0: 詳しい解説と図を `X` 配列(`Q` と同じ添字、全50問)に追加。`x`=詳細解説、`g`=図の配列(`F()`=縦フロー図、`C()`=比較表)。**`Q` の末尾に問題を足したら `X` の末尾にも同じ順で足すこと**(添字がずれると別の問題の解説が出る)。
- v1.3.0: 主要な問題の図を SVG に差し替え(`A()`=アーキテクチャ図、`S()`=シーケンス図、`B()`=棒グラフ。`XG(添字, 図)` が最初のフロー図 `F` を置き換える)。長いラベルは自動で縮小される。
- v1.4.0: ネット情報(AWS 公式試験ガイドは取得不可、検索結果の二次情報)を参考に25問を追加(添字50〜74、`X` も同数)。ドメイン配点は D1=31%・D2=26%・D3=20% が複数ソースで一致、D4=12%・D5=11% は単一ソースのため未確認。公式ガイドで要確認。問題文・解説はオリジナル(転載なし)。AgentCore/Strands/Automated Reasoning 等の新しめの機能は仕様変更が早いので、公式ドキュメントで再確認すること。
- v1.5.0: Q の添字75以降に730問を追加(添字75〜804)。元データ: ①AIP-C01 Trainer の questions.json の単一選択473問(`d` は元の domain-1。複数選択132問は UI が単一選択専用のため未取り込み) ②学習ノート knowledge.zip ベース66問 ③動画2本の字幕ベース191問。これらには `X`(詳細解説・図)が無く、`detail()` は `X` に無い添字では何も出さない(`X` は添字0〜74のみ。追加する場合は添字を合わせること)。
- 動画ベースの問題には `v`="jp"(日本語の約2時間の講座)/"en"(英語の約9時間の講座)、`t`=動画の該当秒があり、解説に「▶ 動画 H:MM:SS から見る」リンクが出る。YouTube は取得不可のため、ユーザーが貼った字幕から作成した。`v` と YouTube ID の対応は `index.html` の `VIDEOS`(jp=V9X5EA9dodE, en=fkUXPT0OJKs は推定。違っていたらそこだけ直す)。
