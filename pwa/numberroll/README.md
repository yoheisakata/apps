# すうじロール

モンテッソーリ教具「ナンバーロール（Number Roll）」のシミュレーター。ながい紙に 1 から順番に数を書いていく活動を、スマホ／タブレットで再現する。日本語UI（ひらがな中心）・単一HTMLファイル。

- 1行10マスの方眼ロールに、画面下のキーで次の数を入力（桁がそろうと自動で丸つけ。まちがえるとマスがゆれる）
- 2回まちがえると薄い数字のヒントが出る（設定でオフ可）。💡ボタンでいつでもヒント
- モンテッソーリの色分け: 1の位=緑・10の位=青・100の位=赤（1000の位は緑に戻る）
- 書いたマスをタップすると同じ1の位の列が光る。「2とび/3とび/5とび/10とび/ゾロめ」で数の模様さがし
- 100ごとに赤い線とラベル、ゴール（100/200/500/1000/10000）達成でお祝い
- 「おてほん」で自動で書いていく／「ひとつもどす」で1つ消す
- 効果音・数の読み上げ（Web Speech API, ja-JP）
- 進み具合と設定は `localStorage`（`numberroll-v1`）に保存
