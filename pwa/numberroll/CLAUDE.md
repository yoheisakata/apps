# numberroll

単一の `index.html`（インライン CSS/JS、ビルド不要、外部依存なし）。モンテッソーリのナンバーロールのシミュレーター。

- 状態は `S`（`next`=次に書く数, `goal`, 各トグル）を `localStorage` の `numberroll-v1` に保存。書いた数は保存せず「1〜next-1 がすべて書かれている」とみなして復元する（順番に書く教具なので）。
- 行は必要な分だけ遅延生成（`ensureRows()`、現在行+1行）。上限 `MAX`=10000（1000行）。`cells[n]` が数 n のマス。
- 1行 = 10マス、行 r は `r*10+1`〜`r*10+10`。100の倍数で終わる行に `.hund`（赤線＋ラベル）。
- 色分けは `digitsHTML()` が位ごとに `c-u/c-t/c-h` を 3 周期で振る（1000の位=緑）。
- 入力は桁数がそろった時点で自動判定（`press()`）。キーボードの数字/Backspace も可。
- もよう: `pattern = {k, col}`。`k` = とび数（11 はゾロ目の特別扱い）、`col` = タップしたマスの1の位。
- ファイルを変更したら `.app-version`（画面上部の `v1.0.0`）を同じコミットで上げる。
