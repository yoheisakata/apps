# もじくえすと 🔤 — `moji-quest/`

子ども向けの文字学習アプリ（Webアプリ・PWA）。旧「まなびアプリ」
（`kids-learning-app/`）から、ひらがな・タイピングの2モードだけを切り出した
もの。たしざん・くくは姉妹アプリの「すうじくえすと」（`suji-quest/`）へ。

## 機能

- **ひらがな(なぞりがき)** — 行を選んで、お手本の文字を**正しい書き順で**
  なぞる練習。1画ずつ、オレンジの●(始点)から線に沿って終点までなぞれた
  ときだけその画が完成し、全部の画が書けたら正解。順番ちがい・線から
  外れる・途中でやめた場合はその画のやりなおしになる。
  筆順データは [KanjiVG](https://kanjivg.tagaini.net/)(CC BY-SA 3.0)を
  使用している。
- **タイピング** — ひらがな1文字/かんたんなことばをローマ字入力で練習。
- 正解すると⭐スターがたまる（`localStorage` に保存）。
- 説明やほめことばの読み上げは同梱の音声ファイル（Open JTalk で生成）を再生
  するので、端末の音声合成の品質に左右されない。オフラインでも鳴る。

## 動かし方

ビルド不要の複数ファイル構成（`index.html` + `app.js` + `style.css`）。
`index.html` をブラウザで開くだけ。オフラインでも使えるよう Service Worker
（`sw.js`）でキャッシュしている。

GitHub Pages のランチャー（My Apps）の「学習」グループに「もじくえすと」
として掲載されている。
