# ⚫️ 囲碁

ブラウザだけで遊べる囲碁アプリ。ビルド不要・依存ライブラリなしの単一 HTML ファイル。

## 遊び方

- ホーム画面で盤の大きさ(9路盤 / 13路盤、デフォルトは9路盤)を選ぶ
- 「対AI対戦」か「2人対戦」を選ぶ
- 対AI対戦では、黒/白と強さ(やさしい/ふつう/つよい)を選べる(黒が先手)
- 盤の交点をタップすると、そこに石を置く(交点そのものに石が乗る、マス目の中ではない)
- 打てない手(すでに石がある・自殺手・コウ違反)をタップすると、下にメッセージが出て何もできない
- 直前の手には緑の点、コウで打ち返し禁止になっている点にはオレンジの輪が表示される
- 「パス」で1手パスできる。両者が連続でパスすると対局終了、地の計算に入る
- 「投了」でいつでも投了できる(相手の勝ちになる)
- 終局すると、黒・白それぞれの石数/地/合計と勝敗がモーダルに表示される

## ルール実装メモ

- 着手・連(グループ)と呼吸点の判定・取り上げ(呼吸点0での相手グループの除去)・自殺手の禁止に対応
- コウは**単純コウルール**のみ実装(直前の1手前の局面を再現する手を禁止)。パスを挟んだ多重コウなど、盤面全体の反復を検出する**超コウルール(スーパーコウ)は未実装**
- 終局判定は両者連続パスのみ。**死石の判定・交渉は未実装**で、盤面に残っている石はそのまま生きているものとして数える
- 得点計算は**中国式・面積制**(自分の石の数 + 自分だけに囲まれた空点の数)。日本式の地合計(生死判定込みの territory scoring)ではない
- 白番のコミは6.5目(引き分け防止のための半目調整)

## 技術メモ

- `index.html` 単体で完結(インライン CSS/JS)、ビルドステップなし
- 盤は交点(グリッドの線の交差点)に石を置く方式。CSS の `grid` + 各交点のセルに疑似要素で線を描画
- AI は本格的な囲碁エンジンではなく、**ヒューリスティック評価**(石を取れるか・呼吸点・自己アタリ回避・自分の眼を埋めない・相手をアタリに追い込めるか・既存の石への近さ、など)でスコアリングした候補手からランダム性を加えて選ぶ簡易ボット
