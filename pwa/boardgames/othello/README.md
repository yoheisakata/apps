# ⚫️ オセロ

ブラウザだけで遊べるオセロ(リバーシ)アプリ。ビルド不要・依存ライブラリなしの単一 HTML ファイル。

## 遊び方

- ホーム画面で「対AI対戦」か「2人対戦」を選ぶ
- 対AI対戦では、黒/白と強さ(やさしい/ふつう/つよい)を選べる
- 盤上の黄色い点が置けるマス。タップすると石を置き、はさんだ相手の石が自動でひっくり返る
- 置ける場所がない場合は自動でパスし、メッセージで知らせる
- 両者とも置けなくなる(または盤が埋まる)と対局終了。石数の多い方が勝ち、同数なら引き分け

## ルール実装メモ

- 合法手 = 石を置いたときに少なくとも1方向で相手の石をはさんで自分の石で挟み込める手のみ
- 8方向すべてを走査してひっくり返す石を収集し、1手で複数方向を同時にひっくり返せる
- パスは自動判定・自動実行(将棋アプリのような確認モーダルは無し、メッセージ表示のみ)

## 技術メモ

- `index.html` 単体で完結(インライン CSS/JS)、ビルドステップなし
- AI はミニマックス + αβ枝刈り。評価関数は角・辺を重視した位置重み表(角=+120、角に隣接する危険マス=-20/-40 など)+ 着手可能数(モビリティ)+ 終盤ほど比重を上げる石数差、の組み合わせ
- 難易度は探索深さ(1 / 3 / 5 手読み)と、最善手からの許容スコア差(スラック、ランダム性)の両方で調整
