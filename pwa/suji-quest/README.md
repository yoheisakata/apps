# すうじくえすと 🔢 — `suji-quest/`

子ども向けの数字学習アプリ（Webアプリ・PWA）。旧「まなびアプリ」
（`kids-learning-app/`）から、たしざん・くくの2モードだけを切り出したもの。
ひらがな・タイピングは姉妹アプリの「もじくえすと」（`moji-quest/`）へ。

## 機能

- **たしざん** — レベル1〜5から選んで、絵文字による数の視覚化つき3択クイズに挑戦。
- **かけざん（くく）** — 段（だん）を選んで九九を順に覚える学習カード。
  Web Speech API（`speechSynthesis`）による読み上げつき。
  「🔊 もういちど きく」で発音を聞き直せる。
- 正解すると⭐スターがたまる（`localStorage` に保存）。
- 説明やほめことばの読み上げは同梱の音声ファイル（Open JTalk で生成）を再生
  するので、端末の音声合成の品質に左右されない。オフラインでも鳴る。

## 動かし方

ビルド不要の複数ファイル構成（`index.html` + `app.js` + `style.css`）。
`index.html` をブラウザで開くだけ。オフラインでも使えるよう Service Worker
（`sw.js`）でキャッシュしている。

GitHub Pages のランチャー（My Apps）の「学習」グループに「すうじくえすと」
として掲載されている。
