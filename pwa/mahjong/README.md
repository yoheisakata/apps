# 🀄 麻雀

ブラウザだけで遊べるリーチ麻雀アプリ。ビルド不要・依存ライブラリなしの単一 HTML ファイル。

**1人プレイ(あなた)vs AI 3人**の対局です。麻雀は本来4人で遊ぶゲームなので、この repo の他のボードゲーム(将棋・オセロなど)にある「対AI対戦/2人対戦」という切り替えはありません — 対局を始めるとそのまま「あなた + AI 3人」で始まります。

## 遊び方

1. ホーム画面で対局の長さ(東1局のみ / 東風戦4局 / 半荘風8局)を選んで「対局開始」
2. 自分の番になったら山から自動的にツモります。手牌の牌をタップすると、その牌を捨てます
3. ツモ和了できるときは「ツモ」ボタンが、暗槓できるときは「暗槓」ボタンが表示されます
4. リーチできる形(面前・テンパイ・持ち点1000点以上)のときは「リーチ」ボタンが出ます。押した後、テンパイを保てる牌をタップすると立直が成立します(1000点払い、以後はツモった牌をそのまま切ることになります)
5. 他家が捨てた牌でロンやポンができるときは、画面下にカードが出るので「ロン」「ポン」「スルー」から選びます
6. 山がなくなると流局になり、テンパイしていた人がノーテンの人から点を受け取ります
7. 局が終わるごとに結果画面が出て、「次へ」を押すと次の局(または最終結果)に進みます
8. 誰かの持ち点がマイナスになるか、設定した局数を終えるとゲーム終了です

## 対応している役・鳴き(実装済み)

- **立直**(リーチ)/ **門前清自摸和**(メンゼンツモ)/ **平和**(ピンフ)/ **断么九**(タンヤオ)
- **役牌**(自風・場風・三元牌の白發中)/ **一盃口** / **対々和** / **七対子**
- **混一色** / **清一色**
- **嶺上開花**(暗槓の直後にツモ和了)
- 鳴きは **ポン** と **暗槓** のみ(下記「未実装・簡略化」を参照)

これ以外の役(三色同順・一気通貫・チャンタ・国士無双・役満各種など)は実装していません。それらでしか成立しない手は「役なし」として和了不可になります(安全側の簡略化 — 誤って点数を出すより、和了できない方を選んでいます)。

## 未実装・簡略化している点(重要)

麻雀は本物のルールがとても広いため、このアプリは意図的にスコープを絞っています。詳しい一覧は同じフォルダの `CLAUDE.md` を参照してください。主なもの:

- **チー(チー宣言による順子の鳴き)は未実装**です。ポンと暗槓のみ対応しています
- **国士無双・役満はすべて未対応**です(役満級の手は安全側で通常役として過小評価されるか、和了不可になります)
- **ドラ・裏ドラ・赤ドラは未実装**です
- **一発・槍槓は未実装**です
- 大明槓(他家の捨て牌をカンする)・加槓(既存のポンをカンに昇格)は未実装。カンは**暗槓のみ**
- 流局時のテンパイ料は実装していますが、複数人の同時ロン(ダブロン)には対応していません — 人間がロン可能な場合は必ず人間側を優先し、見送った場合はその牌を他家にロンとして回しません
- 四家立直・四開槓・九種九牌など特殊な途中流局は未対応。流局は「山が尽きた」場合のみです
- 東風戦のみ(東1局〜東8局相当)。南入・北入はありません。場風は常に「東」固定です

## 技術メモ

- `index.html` 単体で完結(インライン CSS/JS)、ビルドステップなし
- 牌の見た目は Unicode 麻雀牌ブロック(U+1F000–U+1F02B, 🀇🀈🀉…🀄🀅🀆)を使用。フォント非対応環境でも読めるよう、各牌には小さな漢字ラベル(例:「5萬」)を必ず併記しています
- AI は簡易ヒューリスティック(孤立牌・字牌を優先的に切る、対子/順子に近い牌を残す)で、最善手を探索する強い AI ではありません
- 手牌評価・点数計算ロジックは `index.html` 内の `<script>` 冒頭にまとめられており、Node.js から `require()` して単体テスト可能な形(DOM 非依存)になっています。詳細は `CLAUDE.md` を参照
