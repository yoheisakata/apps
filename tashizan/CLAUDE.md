# CLAUDE.md — tashizan

単一 HTML ファイル（CSS/JS インライン）の学習RPG。ビルドなし・依存なし。
共通規約はルートの `CLAUDE.md` を参照（Nunito フォント・ダークグラデ・
モバイルファースト・絵文字アイコン）。

- セーブデータは `localStorage` の `tashizan_save`。**保存形式を変えるときは
  既存セーブの読み込み互換を壊さないこと**（子どもの進行データが消える）。
- UI テキストはすべてひらがな中心の子ども向け日本語。漢字を増やさない。
- 変更後は `index.html` をブラウザで直接開いて動作確認する。
