# たしざんクエスト ⚔️ — `tashizan/`

足し算を解いて勇者を育てる、子ども向けの学習RPG（Webアプリ）。
問題に正解すると経験値とコインがもらえ、モンスターとバトルしながら
レベルアップしていく。

## 機能

- 段階的に上がる難易度の足し算問題
- レベルアップとコイン、ぶき・ぼうぐが買えるショップ
- モンスターバトル
- 実績（じつりょく）システムと効果音
- セーブ機能 — 進行状況を `localStorage`（キー: `tashizan_save`）に保存

## 動かし方

ビルド不要の単一 HTML ファイル。`index.html` をブラウザで開くだけ。
GitHub Pages では https://yoheisakata.github.io/apps/tashizan/ で公開され、
ルートのランチャー（アプリひろば）からリンクされている。
